TENRYU を使う

この節は、要求環境の確認からビルド、最初の実行、Python namelist デッキの記述 (または TENRYU Studio による生成)、HDF5 出力の読み取りまでの実用ワークフロー全体を扱う。以下のクイックスタートと順路に沿えば、この節のページだけで最初の 1 本を完走できる。

クイックスタート（コピーして実行）

前提が揃っているか不安なら、まず動作環境と要求スペックの事前チェックから。以降はリポジトリのルートで実行する。

# 0. ソースコードの入手（初回のみ）
git clone https://github.com/tenryu-code/TENRYU.git
cd TENRYU

# 1. ビルド（初回のみ。詳細と失敗時の対処は「ビルド」ページ）
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
ninja -C build

# 2. 動作確認（登録済みの解析解ケースを 1 本）
./build/tenryu verify noh

# 3. 最初の実行（テンプレートは編集不要でそのまま完走する）
./build/tenryu validate examples/templates/template_1d_slab_radiation.py   # 実行前検査
./build/tenryu run      examples/templates/template_1d_slab_radiation.py  # 本実行

# 4. 結果を見る
ls outputs/template_1d_slab_radiation/results/
python3 -m tools.tenryu_plot profile outputs/template_1d_slab_radiation

（tools.tenryu_plot は numpy・matplotlib・h5py を使う — 要求スペック参照）

ワークフローガイド

動作環境と要求スペック

GPU・コンパイラ・ライブラリの要求と、事前チェックのコマンド。

ビルド

CUDA のリリースビルドの構成、テスト、MPI と ccache の有効化を説明する。

シミュレーションの実行

テンプレートの完走、デッキの書き方、validate/run/verify/freeze、トラブル対処。

namelist リファレンス

最上位のブロック、代表的なキー、単位、正典となる既定値へ案内する。

TENRYU Studio (GUI)

フォーム形式のデスクトップアプリでデッキを作成、検証、保存、実行する。

例題とプリセット

実行可能なテンプレート、検証済みの Studio プリセット、検証用のデッキ集。

出力と解析

3 種の HDF5 と来歴ファイルの全データセットを列挙し、読み方を示す。

初めての 1 本：推奨の順路

  1. 動作環境と要求スペックで GPU・ツールチェーンの前提を確認する。
  2. ビルドで、バイナリと ctest の通る環境を作る。
  3. シミュレーションの実行の手順どおり、テンプレートを validate → run で完走させる。
  4. 例題とプリセットの検証済みプリセット — まずは laser_capsule — を、配布された条件のまま実行する。
  5. 出力と解析に沿って結果を読む。吸収率はエネルギーの台帳（入射と沈着の比）から、爆縮のピークはステップごとの履歴 implosion/rho_peak から読み取る。

物理の詳細が必要になったら物理カーネルの該当ページへ。各ページの「物理機構」の節が、式に入る前の背景を説明する。時間刻みの決まり方は時間刻み制御と CFL にまとめてある。
