チェックポイントと再開 reference

チェックポイント <name>_ckpt_NNNN.h5 は、スナップショットの内容に加えて、再開（restart）に必要な内部状態を保存する HDF5 である。この頁は、スナップショットに追加されるグループと、再開の互換規約（schema_version と凍結設定の照合）を述べる。ファイルの命名・保持数・停止要求のファイルは出力と解析の頁、再開の指定方法は実行の頁にある。

チェックポイントの追加内容と再開の互換性

チェックポイントはスナップショットの内容に加えて、再開に必要な内部状態を保存する。

グループ内容
hydro_flags/hydro_activeセルの流体活性マスク。
time_state/スナップショットと共通の step・t・dt に、累積エネルギー項と user_seed（Main.seed の値）が加わる。再開時の Δt はここから引き継がれる。Main.seed が user_seed と違うと、再開は ConfigError で拒否される。
output_state/次回出力予定時刻（t_next_plot・t_next_history・t_next_checkpoint）。
hydro/cv_e・cv_i・cs（1D）状態方程式（equation of state、EOS）から求めた比熱と音速。これらがあるチェックポイントからの 1D の再開は再クロージャ（re-closure。定義）をやり直さず、途中から再開した run が元の run とビット一致で続く（光線追跡の再利用 Laser.raytrace_skip_config.enabled=True の run を除く）。
hydro_flags/cell_is_void（1D）ボイドセル（Material.is_void の材料のセル。定義）の印。1D は常に書き（空セルがなければ 0）、2D は実行がマスクを持つときだけ書く。
conduction_state/熱伝導ソルバの run 全体の累積統計（反復数・残差・条件数の最大など）。
burn_state/specific_inventory核燃焼の比インベントリ（specific inventory）\(Y_s\) [1/g]（セルごとに D・T・He3・He4・p の順）。再開は、スナップショットの数密度 hydro/burn_n_* を密度で割った値ではなくこれを使う（2026-09-26 から）。
radiation_sn/（1D SN）線形不連続法の角度分布（psi_prev・psi_sd_prev）とセル内の電子エネルギーの差（ee_node_offset）。無いチェックポイントからは等方・一様で始める。
particles/・rng/schema 1 のチェックポイントだけが持つ。particles/ は退役したモンテカルロ輻射の粒子プールで、空なら読み、粒子があれば再開を拒否する。rng/ は乱数状態で、再開では読まない。schema 2（2026-09-29）ではどちらも書かない。

再開の互換規約: schema_version（現行は 2026-09-29 からの 2）が現行と同じなら通常読込、古い（または欠落）なら不足項目を既定値で補う後方互換読込、新しいなら読込拒否。チェックポイントの凍結設定（デッキ本文のハッシュと、Main.restart_from を除くすべての設定）が再開に使うデッキと一致しなければ、再開は拒否される。再開の指定方法は実行ページを参照のこと。
