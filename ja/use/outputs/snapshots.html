スナップショット reference

スナップショット <name>_NNNN.h5 は、ある時刻の空間場を書いた HDF5 である。この頁は、ルート属性と、グループ（metadata/・mesh/・hydro/・diagnostics/・radiation/・laser/）ごとの主なデータセットを一覧にする。ファイルの命名と出力間隔は出力と解析の頁、時系列の診断量は履歴の頁にある。データ型・配列形状まで含む正典はリポジトリの docs/SPECIFICATION.md §7（要約は docs/OUTPUT_SCHEMA.md）である。

スナップショットのデータセット

ルート属性は t（時刻 [s]）、dt（Δt [s]）、cycle と step（どちらもステップ番号）、geometry（"1D_SPH"|"2D_RZ"）、nr・nz（Mesh.nr と、2D の Mesh.nz。1D の nz は 1）、n_cells、n_nodes、n_groups、n_materials、two_temperature（常に 1）、schema_version である。再開が元の run の厳密な継続でないとき（たとえば、Numerics.ale.band_ale の状態を保存した補助ファイル、すなわちチェックポイントの名前に .band-state を付けたファイルが無いチェックポイントから再開したとき）は、その印を文字列のルート属性 restart_provenance（例: RESTART_WITHOUT_BAND_STATE）に書く。geometry は 1D では平面・円筒でも "1D_SPH" なので、1D のファイルは座標系を表す geometry_1d（"spherical"|"cylindrical"|"planar"）も持つ。1D では配列は 1 次元フラット、mesh/x_z・v_z は省略される。以下、グループごとに列挙する（「optional」は生成条件付き）。

metadata/ — 来歴

データセット内容
namelist_source実行したデッキ（Python ソース全文）。
frozen_config凍結設定の JSON（config/<name>_frozen.json との違いは来歴の節）。属性として build_type（Release または Debug）・gpu_name（デバイス 0 の GPU 名）・rng_seed（Main.seed の値）を持つ。git_hash と cuda_arch は常に "unknown"、n_ranks は常に 1 であり、実行の同定には使えない。
group_bounds_eV輻射群（radiation energy group）の境界 [eV]（長さ G+1）。

mesh/ — 節点と接続

データセット内容
x_r, x_z節点座標 [cm]。x_z は 2D のみ。
v_r, v_z節点速度 [cm/s]。v_z は 2D のみ。
cell_material_idセルの代表材料インデックス（多材料セルは体積分率最大、同率なら小さい方）。
topology/v2/・v3/・v4/optional。マルチブロックメッシュ（multiblock mesh）の接続関係（mesh topology。v2: 3 ブロック、v3: half-butterfly 5 ブロック — block/seam 表と CSR（compressed sparse row、圧縮行格納）形式の接続関係、v4: 五角形帯の cell_nverts と corner_stride 属性）。単一ブロックでは省略。構成の詳細は 2D メッシュ参照。

hydro/ — セル中心の流体・熱力学状態

データセット内容
rho, Te, Ti密度 [g/cm³]・電子/イオン温度 [eV]。
ee, ei電子/イオン比内部エネルギー（specific internal energy）[erg/g]。
Pe, Pi, Qvisc電子/イオン圧力・人工粘性圧（artificial viscosity pressure）[dyne/cm²]。
mass, volセル質量 [g]・体積 [cm³]。
zbar平均電離度（mean ionization）。
volFrac材料の体積分率（volume fraction）[N_cell, N_mat]（多材料時）。
burn_rate, burn_Q_e, burn_Q_i, burn_eps_cum, burn_n_*optional（核燃焼（nuclear burn）を有効にした Burn.enabled=True のとき）。反応率密度 [1/cm³/s]、燃焼生成物による電子・イオンの加熱率 [erg/cm³/s]、累積の比沈着エネルギー [erg/g]、D・T・He3・He4・p の数密度 [1/cm³]。1D では、セルで生まれた中性子の累積数 burn_neutron_cum も書く。
shock_timeoptional。最後に衝撃波を検知した時刻 [s]（post-shock 系機能の有効時）。
adaptive_av_gate, adaptive_av_mode_celloptional。適応人工粘性（adaptive artificial viscosity、AV）のセルごとの重み g_i（データセット名の gate。無次元）と、g_i > 10-6 のセルを 1 とする可視化用マスク（Numerics.hydro.adaptive_av.enabled=True のとき。1D の av_type="vnr" 専用）。
corner_massoptional。2D のサブゾーンコーナー質量（subzonal corner mass。定義）[g]（ラグランジュ不変量）。
eta_compatibleoptional。旧 compatible 診断の体積差不整合 [cm³]。
per_material/v1/optional。材料別の質量 mass [g] と電子・イオンの内部エネルギー Ee・Ei [erg]（セルと材料の組ごと。Numerics.materials.per_material_conservation_enabled=True 時）。
gas_tracer_Yoptional。ホットスポットのガストレーサ Y_g（用語。無次元、セルごと）。Numerics.diagnostics.hotspot_gas.enabled=True でトレーサを初期化した run が書く。チェックポイントから再開した run は、これを読み戻して続ける。

diagnostics/ — スナップショット側の物理診断（optional）

グループ有効条件と内容
areal_density/v1/Diagnostics.areal_density.enabled=True。角度列 angles_deg と面密度（areal density）rhoR [g/cm²]、optional の rhoR_hotspot_tracer（密度にホットスポットのガストレーサ Y_g を掛けた積分 ∫ρY_g ds。用語）。
hotspot_gas/v1/Numerics.diagnostics.hotspot_gas.enabled=True。ホットスポットのガス（用語）の Te/Ti 統計（質量重みの mean/p10/p50/p90。Ti は 2 温度のときだけ）、エネルギー（internal/kinetic/total とその初期値）、仕事プロキシ（work proxy）、その定義の文字列 hotspot_work_definition。

radiation/ — 輻射場と輻射診断

データセット内容
energy_density群別輻射エネルギー密度 E_g [erg/cm³]（[N_cell, G]）。
rad_dep, rad_emit当該ステップ累積の吸収・放出 [erg]（群別）。
deposited_power吸収パワー密度 [erg/cm³/s]（= rad_dep/(VΔt)、可視化用）。
fleck_factor2D の FLD（flux-limited diffusion、流束制限拡散）のみ。セルの Fleck 因子（Fleck factor）。診断はグレイ（gray）の G=1 のときだけ有効である。
sn_tau_R, sn_reduced_flux, sn_ap_alpha2D の SN（discrete ordinates、離散座標法）のみ。面の流束を SN と拡散で混ぜる漸近保存（asymptotic-preserving、AP）処理の診断（光学的厚さ（optical depth）・換算流束（reduced flux）・混合の重みの各プロキシ）。
diag_*（12 種）1D SN の出力専用診断: diag_rad_ に続く E_pre/E_post/emission_at_Tn/emission_at_Tnp1/absorption と、diag_ に続く clip_energy/clip_full_deficit/chi_opacity/F_first_moment/E_star_flux/stream_theta/ap_alpha_face。再開の状態復元には使われない。

laser/ — レーザー（Laser.enabled=True 時のみ）

データセット内容
deposited_powerレーザー沈着パワー密度 [erg/cm³/s]。
absorption_fraction全体吸収率。吸収の累積を、吸収・未吸収・E_cbet_iaw の累積の和で割った値で、受け皿がなく捨てられたレーザーエネルギーがなければ吸収 / 入射に等しい。
E_ra, E_cbet_iaw, E_cbet_iaw_stepスカラー [erg]。共鳴吸収（resonance absorption）で吸収されたレーザーエネルギーの累積、CBET（cross-beam energy transfer、交差ビームエネルギー転送）がイオン音波（ion-acoustic wave、IAW）へ渡したエネルギーの符号付きの累積とそのステップの値。履歴の energy/laser_ra_deposited・energy/E_cbet_iaw・energy/E_cbet_iaw_step と同じ量である。
ray_density光線の初期配置密度 [1/cm³]。
A_Q_r_shells, A_Q_z_shells2D の単一ブロックのメッシュのみ（マルチブロックのメッシュには書かない）。セル列（A_Q_r_shells は r 添字を固定した z 方向のセルの列、A_Q_z_shells は z 添字を固定した r 方向のセルの列。データセット名の shells はこの列を指し、カプセルのシェルではない）ごとの沈着非対称度 \((q_{max}-q_{min})/(q_{max}+q_{min})\)。q は各セルにそのステップで沈着したレーザーエネルギー [erg]。
mesh/ray_output_trajectory=True の非 skip ステップ（= 光線追跡（ray tracing）を実行したステップ。Laser.raytrace_skip の間引き再利用ステップでは出力されない）のみ。レーザー専用の独立格子 LaserMesh（流体メッシュとは別の 2D RZ 構造格子 — レーザー参照）の節点座標・\(\hat n_e\)（電子密度の臨界密度（critical density）に対する比）・T_e・Z̄・密度勾配・n_crit。
rays/ray_output_count>0 の非 skip ステップのみ。光線の初期位置・方向・パワー（1D: R0/Z0/vR0/vZ0、2D: x0/y0/z0/vx0/vy0/vz0）とビーム ID。
rays/trajectory/ray_output_trajectory=True 時。CSR 形式の軌跡（offsets・step_count・位置列・残存パワー列）。可視化で光線を重ねて描くときの元データ。

mode="radial_absorption_1d" では物理的な光線の軌跡がないため、deposited_power と absorption_fraction は通常どおり出力されるが rays/ 系は空または未作成となる。なお、退役したモンテカルロ輻射（Monte Carlo radiation）の出力（radiation/ddmc_flag・radiation/delta_E_rad_prev・holo/・difference/）は schema 2（2026-09-29）から書かない。それより前のファイルには残っていることがある。
