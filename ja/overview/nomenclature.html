記号・用語集 reference

このページは、ドキュメント全体が前提とする語彙をまとめたものである：バージョン表記、略語、外部コード・施設名、凍結された cgs + eV 単位系の共有定数、そしてページによって意味の変わる記号の対照表。各カーネルページは記号を使用箇所で定義するが、近くに定義が見当たらないときはここを参照のこと。

バージョン表記

本ドキュメントが記述するのは TENRYU v1（v1.0 とも表記）— 現行のプロダクション世代である。小文字の「v」はコード全体のリリースではなく、モデル・機能の世代を表す。

表記意味
v1 / v1.0本サイトが記述する TENRYU のプロダクション世代。「v1 は輻射圧を省く」等の記述はこの世代へのスコープ宣言。
burn v2 /「Version 2」核燃焼カーネルの第 2 世代モデル（遮蔽・多群荷電粒子拡散・モンテカルロ α 輸送）。
burn v2-Eburn v2 の中性子加熱拡張（2 ライン初回衝突モデル）。
MPI v1第 1 世代 MPI 移植（監査済み機能スコープと deferral ガードは MPI ページ参照）。
M1 v1ALE ページの M1/TMOP リゾーンソルバの第 1 世代。
V3（hydro）流体ページに現れる実験的な 1D 解適応 ALE 経路の内部機能名。検証デッキ名 2d_rz_v3_smooth_temporal（midpoint_v1 の収束次数を測る）とは無関係。
pc_v0, midpoint_v1, bbsw_radial_v0 …接尾辞がそのアルゴリズムの世代を記録する namelist 値。旧世代は凍結構成の互換のため保持される。

cgs + eV 単位系の共有定数

単位系は凍結：長さ cm、時間 s、質量 g、エネルギー erg、密度 g/cm³、温度・光子群境界は eV。全物理ページに共通する規約は次の 3 つである。

  • \(k_B\) は eV_to_erg \(=1.6022\times10^{-12}\) erg/eV を意味する。温度が eV で保持されるため、本ドキュメントの \(k_BT\) はすべて eV→erg 変換であり、ケルビン系のボルツマン定数は現れない。
  • \(a_{\rm eV}=1.3720\times10^{2}\) erg cm⁻³ eV⁻⁴ は eV 単位系で表した輻射定数。平衡輻射エネルギー密度は \(T\) を eV として \(a_{\rm eV}T^4\)。
  • \(m_p=1.6726\times10^{-24}\) g は陽子質量。数密度は \(A\) を amu として \(n_i=\rho/(A\,m_p)\) — TENRYU は原子質量単位を意図的に \(m_p\) と同一視する。真の amu との約 0.8% の差は、材料の実効 \(A\) に吸収される固定の文書化済み規約。

複数の意味を持つ記号

複数の分野で標準になっている文字の対照表である。文脈（ページ）が意味を選ぶ。

記号文脈ごとの意味
\(\alpha\)Fleck 陰性度パラメータ（既定 1.0、FLD）／曲率フープ項の幾何係数（粘性：円筒 1・球 2）／Winslow 計量係数（ALE）／\(\alpha_{iaw}\) は CBET のイオン音波減衰率。
\(\beta\)輻射–物質剛性比 \(4a_{\rm eV}T_e^3/C_{v,e}\)（FLD）／SNB の規格化電子エネルギー \(E/(k_BT_e)\)（\(\hat\beta\) は大域端）／Winslow 計量係数・M1 バリア重み（ALE）。
\(\lambda\)FLD リミッタ関数 \(\lambda(R)\)／SNB 群停止長 \(\lambda_g\)（abs/tr 変種）／ALE ラインサーチのブレンド係数／\(\lambda_0\) はレーザー真空波長。
\(\theta\)伝導の調和フラックス制限係数／CBET の theta_cap／\(S_N\) の donor-\(\theta\) リミッタ／極角。
\(g\)光子・電子エネルギー群添字（輻射・SNB・ホット電子・燃焼）／CBET では利得曲線 \(P(g)\) の規格化離調 — CBET ページの集計「群」添字は第 3 の無関係な整理番号。
\(f\)Fleck 因子 \(f_{c,g}\)／伝導の自由流フラックス割合 f_lim／陽的ソース時間刻み割合 \(f_E\)（explicit_source_limit）／CBET 較正係数 f_cbet／ホット電子捕獲密度割合 \(f_s\)（source_nc_fraction）／燃焼のイオン加熱割合 \(f_i\)／CBET のドナーキャップ係数 \(f_g\)。
\(R\)FLD リミッタ引数 \(|\nabla E_g|/(\sigma_{R,g}E_g)\)／\((R,Z)\) の径座標／SNB G2 ゲートのフラックス応答比／粘性のチャネル比 \(\eta_e/\eta_i\)。
\(E\)群輻射エネルギー密度 \(E_{c,g}\)／粒子運動エネルギー（ホット電子・燃焼の群格子）／2D 伝導更新の保存的セル熱エネルギー \(E_c\)／筆記体 \(\mathcal E\) は SNB 電場オプションの静電場。
\(e\)比内部エネルギー \(e_i,e_e\) [erg/g]（添字はイオン種・電子）／臨界密度 \(m_e\omega_0^2/(4\pi e^2)\) や衝突率の式では素電荷／\(e^{-2}\) スポット半径などでは指数の底。
\(u\)流体速度 \(\mathbf u\)／ホット電子スペクトル式では規格化エネルギー \(u=E/T_h\)（\(u_{g\pm1/2}\) は群端、\(u_{min},u_{max}\) は窓端）。
\(k\)\(k_BT\) の eV→erg 変換（上記定数）／分散・減衰式の摂動波数／\(\mathbf k\) は CBET の光波ベクトル。
\(m_i\)ホット電子 dt リミッタではセル \(i\) の質量／CBET の音速では平均イオン質量 \(\bar m_i=A_{eff}m_p\)。
添字 \(i\), \(j\)\(T_i,e_i,P_i\) ではイオン種／1D の離散化ではセル添字 \(i\)（\(V_i,\Delta M_i\)）と節点添字 \(j\)（\(r_j,u_j\)）。種別か格子かは文脈が選ぶ。
\(M\), \(M_c\), \(\Delta M_i\)いずれもラグランジュセル質量（1D は \(\Delta M_i\)、2D は \(M_c\)）。燃焼の \(M_{req}/M_{max}\) はサブサイクル数（要求値 vs subcycle_max）。
\(\Delta l_c\)dt 制限が使うセル代表長：1D はセル幅、2D は \(\sqrt{A_c}\)（\(A_c\) は子午面セル面積）。
\(T_h\)（= \(T_{hot}\)）ホット電子指数スペクトル温度（T_hot_eV、内部で erg に変換）。
\(n_c\), \(n_{\rm crit}\)同一量 — レーザー臨界密度 \(m_e\omega_0^2/(4\pi e^2)\)。ホット電子ページは \(n_c\)、レーザーページは \(n_{\rm crit}\) と表記。
\(Z_{\rm eff}\), \(\bar Z_{\rm eff}\)\(Z_{\rm eff}=\bar Z r_2\) は電荷状態モーメントによる衝突実効電荷（\(r_2=\langle Z^2\rangle/\bar Z^2\)）；\(\bar Z_{\rm eff}\)（と \(A_{\rm eff}\)）は混合セルの組成平均。検証タグ R2 は \(r_2\) と無関係。
L1 / L2レーザー検証ゲート階層（ゲートタグ凡例）；\(L_2\)/\(L_\infty\)（\(\varepsilon_{L2}\), \(\varepsilon_{L\infty}\)）は相対誤差ノルム（場全体の RMS / 最大値）。
\(w_m\), \(w_k\), \(w_0\)\(w_m\)：\(S_N\) 求積重み（1D Gauss–Legendre 集合は \(\int_{-1}^1d\mu=2\) に規格化、方位角は \(\psi\) に畳み込み；よって \(\sum_{\mu_m>0}w_m\mu_m=1/2\)）；\(w_k\)：レーザー環状レイ重み（プロファイル×厳密面積、総和 1）；\(w_0\)：ビームの \(e^{-2}\) スポット半径。

検証タグ

検証の語彙 — 再現性ティア（T-bit / T-sum / T-noise / OFF-bit / envelope）と各カーネルのゲートタグ族（L1/L2、G1–G4、G-R/K/P/L、B/N/W、H1/H2、I1/I2/I3/I6、R2、LR07/LE08/FLD-CED）— は検証とベンチマークページの再現性凡例とゲートタグ凡例で一元的に定義されている。
