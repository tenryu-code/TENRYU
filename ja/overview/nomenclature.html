記号・用語集 reference

このページは、ドキュメント全体が前提とする語彙をまとめたものである：バージョン表記、略語、外部コード・施設名、固定した cgs + eV 単位系の共有定数、そしてページによって意味の変わる記号と語の対照表。各物理カーネルのページは記号を使用箇所で定義するが、近くに定義が見当たらないときはここを参照のこと。

バージョン表記

本ドキュメントが記述するのは TENRYU v1（v1.0 とも表記）である。公開版 v1.0.0-beta.1（tenryu --version が表示する 1.0.0-beta.1）に対応する。下の表の v2-E、MPI v1、M1 v1 は、コード全体の版ではなく機能ごとの呼び名で、コードのエラー文に出る。

表記意味
v1 / v1.0本サイトが記述する TENRYU の版。公開版 v1.0.0-beta.1 に対応する。「v1 は輻射圧を省く」のように、この版が扱う範囲を述べる文に使う。
v2-E核燃焼の中性子加熱モデル Burn.neutron_heating の呼び名。DT 反応の中性子（14.049 MeV）と DD 反応の中性子（2.449 MeV）の 2 本の線スペクトルについて、燃料の D、T との最初の衝突での加熱を、1 回の飛行で評価する。2D RZ では Burn.neutron_heating=True を拒否するエラー文に、この呼び名が出る。
MPI v1MPI（Message Passing Interface）のランク（rank）数が 2 以上のとき、未対応の機能を拒否するエラー文に出る呼び名。拒否するのは、1D のボイド（void）領域、適応人工粘性（adaptive artificial viscosity）、Braginskii 粘性である（ソースは src/hydro/hydro_1d.cu）。複数ランクで使えない機能の一覧は、MPI のページの適用範囲と先送りの保護の節にある。
M1 v1ALE（arbitrary Lagrangian–Eulerian）のリゾーン（rezone）ソルバ Numerics.ale.rezone_solver="m1_tmop"（M1/TMOP。TMOP は target-matrix optimization paradigm の略）の、入力検査と実行時のエラー文に出る呼び名。対象は極座標族の論理メッシュ（polar-family logical mesh）だけで、Mesh.logical_mesh_2d が rectangular_rz または cone_shell のときは、入力検査が「not supported in M1 v1」で拒否する。実行時には四角形メッシュだけを受け付ける（ソースは src/hydro/ale_driver.cu）。
pc_v0, midpoint_v1, bbsw_radial_v0, kinematic_basis_rz_v1末尾に _v0、_v1 が付く namelist の値。接尾辞は値の名前の一部で、版を表す記号ではない。Numerics.hydro.time_integration は、pc_v0（予測子–修正子法、predictor–corrector method）か midpoint_v1（中点法、midpoint method）を選ぶ。Numerics.hydro.corner_mass_convention は、bbsw_radial_v0（半径方向に線形な従来のコーナー質量の集中化、lumping）か kinematic_basis_rz_v1（双一次の運動学基底を R で重み付けした集中化）を選ぶ。既定と使い分けは、ラグランジュ流体のページの時間積分とコーナー質量の節にある。

cgs + eV 単位系の共有定数

単位系は固定である：長さ cm、時間 s、質量 g、エネルギー erg、密度 g/cm³、温度・光子群境界は eV。全物理ページに共通する規約は次の 3 つである。

  • \(k_B\) は eV_to_erg \(=1.6022\times10^{-12}\) erg/eV を意味する。温度が eV で保持されるため、本ドキュメントの \(k_BT\) はすべて eV→erg 変換であり、ケルビン系のボルツマン定数は現れない。
  • \(a_{\rm eV}=1.3720\times10^{2}\) erg cm⁻³ eV⁻⁴ は eV 単位系で表した輻射定数。平衡輻射エネルギー密度は \(T\) を eV として \(a_{\rm eV}T^4\)。
  • \(m_p=1.6726\times10^{-24}\) g は陽子質量。数密度は \(A\) を amu として \(n_i=\rho/(A\,m_p)\) — TENRYU は原子質量単位を意図的に \(m_p\) と同一視する。真の amu との約 0.7% の差は、材料の実効 \(A\) に吸収される固定の文書化済み規約。

複数の意味を持つ記号と語

複数の分野で標準になっている文字の対照表である。文脈（ページ）が意味を選ぶ。

\(\lambda\)FLD リミッタ関数 \(\lambda(R)\)／SNB 群停止長 \(\lambda_g\)（abs/tr 変種）／ALE ラインサーチのブレンド係数／\(\lambda_0\) はレーザー真空波長。
\(\theta\)伝導の調和フラックス制限係数 \(1/(1+|q|/q_{max})\)／CBET の theta_cap（1 回の交差で供給側が失える割合の上限）／\(S_N\) の供給セル（上流で輻射エネルギーを送り出す側のセル）が、そのステップで使える輻射エネルギーを超えて送り出さないよう、送出量を縮小する 1 以下の係数（定義はSN のページの用語）／極角。
\(\kappa\)質量不透明度 [cm²/g]（輻射・EOS/不透明度）。伝導の文脈では電子熱伝導率（\(\kappa\propto T_e^{5/2}\)）。\(\kappa_{\rm IB}\) は逆制動輻射の吸収係数（レーザー）。
\(\sigma\)長さあたりの不透明度（length opacity）\(\sigma=\rho\kappa\) [cm⁻¹]（添字 a は吸収、s は散乱、t は全消衰（total extinction）、R はロスランド平均（Rosseland mean）、P はプランク平均（Planck mean）。輻射・EOS/不透明度）／標準偏差（変動係数 \(\sigma/|\mu|\)）／\(\langle\sigma v\rangle\) では核反応の断面積（燃焼）／CBET ではシートの添字（0 = 入射側、1 = 出射側）／1D メッシュのページの \(\sigma_{\rm sg}\) はスーパーガウス型の重みの幅（grading.sg_sigma）／ALE のページの \(\sigma_b\) は、障壁項（barrier term）が働き始めるヤコビアンの比（0.1）。
\(\chi\)CBET では結合係数（coupling coefficient。対の交換 \(\Delta P_{A\leftarrow B,c}=\chi\,L_{A,c}L_{B,c}/V_c\) の比例係数）／ALE のページの \(\chi_e\) は、短辺の融合の判定量 \(\ell_e^2/(\delta_e h_e)\)（辺の長さの二乗を、座標の表現間隔 \(\delta_e\) と局所スケール \(h_e\) の積で割った値。4 以下の辺を融合する）。
\(\psi\)\(S_N\) の方向別の輻射強度（specific intensity）\(\psi_{g,m}\)（群 \(g\)、方向 \(m\)）／流体の CSW 形式の人工粘性では Christensen の制限関数（衝撃波の足元と後端で 0、速度が線形な圧縮で 1）／CBET では 2 本のビームの交差角（\(\cos\psi=\hat k_q\cdot\hat k_p\)）。
\(g\)光子・電子エネルギー群添字（輻射・SNB・ホット電子・燃焼）／CBET では利得曲線 \(P(g)\) の規格化離調 — CBET ページの集計「群」添字は第 3 の無関係な整理番号。
\(f\)Fleck 因子 \(f_{c,g}\)／伝導の自由流フラックス割合 f_lim／陽的ソース時間刻み割合 \(f_E\)（explicit_source_limit）／CBET 較正係数 f_cbet／ホット電子捕獲密度割合 \(f_s\)（source_nc_fraction）／燃焼のイオン加熱割合 \(f_i\)／CBET の供給側の上限（donor cap）の係数 \(f_g\)。

\(e\)比内部エネルギー \(e_i,e_e\) [erg/g]（添字はイオン種・電子）／臨界密度 \(m_e\omega_0^2/(4\pi e^2)\) や衝突率の式では素電荷／\(e^{-2}\) スポット半径などでは指数の底。

\(u\)流体速度 \(\mathbf u\)／ホット電子スペクトル式では規格化エネルギー \(u=E/T_h\)（\(u_{g\pm1/2}\) は群端、\(u_{min},u_{max}\) は窓端）。
\(k\)\(k_BT\) の eV→erg 変換（上記定数）／分散・減衰式の摂動波数／\(\mathbf k\) は CBET の光波ベクトル。

\(T_h\)（= \(T_{hot}\)）ホット電子指数スペクトル温度（T_hot_eV、内部で erg に変換）。

複数の意味を持つ語

記号のほかに、同じ語がページによって別のものを指す場合がある。次の表は、その語の意味と、この文書での書き分けを示す。

語文脈ごとの意味
カーネル物理カーネル（physics kernel）は、1 つの物理演算子とそのページである（物理カーネルのページの定義）。CUDA カーネルは、GPU 上で並列に実行される関数である。積分核（kernel）は数学の用語で、核燃焼のページの Fraley の保持率に使う「点源球のカーネル」がこれに当たる。この文書は、前者を「物理カーネル」、後者を「CUDA カーネル」と書き分ける。
凍結凍結（freeze）は、デッキの内容を、時間ループに入る前に、ループの中で変わらない形に確定する操作である（実行のページの用語）。デッキの Python の関数を数値の表に置き換えることと、既定値を補った設定の全体を 1 個の JSON（凍結設定）にすることを指す。凍結設定は HDF5 の出力の metadata/frozen_config にも保存され、tenryu freeze は凍結設定だけを書き出す。値を変えずに保つこと（段のあいだ係数を変えない、など）は「固定する」と書き、凍結とは書かない。
シードCBET のページのシード（seed）は、対の結合係数を求めるとき標本点を出す側の状態で、もう一方がポンプである（区画、シードとポンプ、影）。乱数の種は「乱数の種（random seed）」と書き、Main.seed で与える。GXII の回帰デッキが外側に置く低密度の指数ランプは、シード・コロナ（seed corona）である（試験のタグと用語の凡例）。
基準解基準解（golden）は、承認した実行の指標値を保存した参照値で、同じ格子と実行条件での変化の検出器である（凡例）。独立に用意した解 — 閉じた形の解、半解析的な解、ODE の数値解 — は参照解（reference solution）と書き、基準解とは別のものとして使い分ける。
部分サイクル部分サイクル（subcycling）は、1 つの時間刻み \(\Delta t\) を、より小さい刻みに分けて進めることである。核燃焼では、反応ネットワークを陽的中点法で進めるのに要る分割数 \(M_{req}\)（上限は Burn.subcycle_max）を指す。電子熱伝導では、陽的な安定限界 \(\Delta t_{exp}\) の刻みで \(\Delta t\) を進める回数を指す。同じ名前で別の量なので、ページごとの意味を読むこと。この文書は「サブサイクル」ではなく「部分サイクル」と書く。
クロージャクロージャ（closure）は、方程式の未知量を決める関係式やモデルである。物質のクロージャは、EOS で密度 \(\rho\) と比内部エネルギー \(e\) から温度 \(T\)、圧力 \(P\)、比熱 \(c_v\) を求める関係で、再クロージャ（re-closure）は、演算子が状態を変えるたびにこれを求め直すことである（演算子分割と再クロージャ）。輸送のクロージャは、面の熱伝導率を左右のセルの値から作る規則、拡散のフラックスリミッタ、エディントン因子などである。エネルギーなどの収支が誤差の範囲で成り立つことは「収支が閉じる」と書き、クロージャとは書かない。

試験のタグと再現性の判定方式

試験名と各物理カーネルのページに現れるタグ — L1/L2（レーザー）、G1–G5（SNB の熱伝導）、G-R/G-K/G-P（核燃焼）、H1/H2（2D 流体）、I1/I2/I3/I5/I6（2D RZ の統合試験群）、R2（2D RZ の SN 輻射の試験群）、LR07/LE08/FLD-CED（I1 の参照解）— の意味と、再現性の判定方式（ビット単位、縮約順序の帯、雑音帯、機能オフの一致、envelope）は、検証とベンチマークのページのタグ凡例と再現性の検査で定義している。
