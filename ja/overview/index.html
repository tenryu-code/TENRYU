概要

TENRYU は、エネルギー整合（compatible）なラグランジュ流体（Lagrangian hydrodynamics）を中核とし、複数の物理演算子（physics operator）をストラング分割（Strang splitting）で時間発展させる構成である。この節では、コードの対象範囲と設計原則、モジュール構成、すべての物理カーネル（1 つの物理演算子を扱うページの単位）に共通する数値基盤、そしてすべての変更を判定する検証（verification）の哲学を説明する。

概要ガイド

アーキテクチャとモジュール地図

入力の Python ファイル（デッキ、deck）から、GPU 上の状態（State）、物理演算子、HDF5（Hierarchical Data Format 5）形式の出力までの流れをたどる。

数値基盤

単位系、共通の支配方程式とクロージャ（closure）、状態量の配置、演算子分割（operator splitting）、床（floor）とクランプ（clamp）、エネルギー台帳（energy ledger）を説明する。

時間刻み制御と CFL

大域時間刻み（global time step）Δt の決定則と、物理カーネルごとの CFL（Courant–Friedrichs–Lewy）条件・安定条件の式を一覧する。

MPI 分割

各ランク（rank。MPI の 1 プロセス）が更新を受け持つ範囲である所有ウィンドウ（owned window）、隣のランクの値の複製を受け取るゴースト交換（ghost exchange）、全ランクの部分値を 1 つにまとめる縮約（reduction）の再現性。

検証の哲学

解析解（analytic solution）による検査、基準解（golden）との回帰（regression）、再現性（reproducibility）の試験、ベンチマークによる証拠の積み上げを示す。

記号・用語集

バージョン表記、略語、外部コード名、共有定数、複数の意味をもつ記号と語の対照表。
