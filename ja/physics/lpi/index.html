LPI（レーザープラズマ相互作用）

レーザープラズマ相互作用（laser–plasma interaction、LPI）は、レーザー光とプラズマの波が結合して、逆制動輻射（inverse bremsstrahlung、IB）による吸収とは別の経路でエネルギーを移す過程の総称である。TENRYU が扱う LPI の効果は 2 つある。交差するビームのあいだでイオン音波（ion-acoustic wave）を介して光のパワーを移す交差ビームエネルギー転送（cross-beam energy transfer、CBET）と、四分の一臨界密度付近の不安定性が作るホット電子（hot electron）の生成、輸送、物質へのエネルギー付与である。どちらもレーザー演算子の内部の処理である。CBET は光線のパワーを変える。ホット電子輸送はレーザーの捕獲記録にあるパワーを使って物質へエネルギーを付与する。波の成長や飽和、後方散乱（backscatter）の反射光は解かない。この頁は 2 つの効果の位置づけ、光線追跡との受け渡し、演算子の列の中での位置、1D と 2D RZ の対応、入口となるキーを説明する。各効果の式とアルゴリズムは子の頁で説明する。

CBET

交差するビームのあいだで、イオン音波を介して光のパワーを移す保存型の交換。ポートの配置と波長離調を扱う。

ホット電子

較正した変換効率とスペクトルによる、ホット電子の生成、輸送、物質の予熱。

ホット電子の輸送の解析解による検証

3 つの一次元問題でエネルギーの付与、逸出、飛行中の残量を解析解と比べる。

扱う効果と扱わない効果

扱う効果。CBET とホット電子の 2 つである。

  • CBET：2 本のビームのビートがポンデロモーティブ力（ponderomotive force）でイオン音波を駆動し、その音波を介して一方のビームから他方へパワーが移る。TENRYU は、線形・定常・強減衰（strongly damped）の局所平面波の利得 [1] でこの交換を評価し、1 回の交換でパワーの総和を保つ。波長離調（wavelength detuning）があるときは、イオン音波へ渡したパワーを符号付きの台帳 E_cbet_iaw に記録する。
  • ホット電子：2 プラズモン崩壊（two-plasmon decay、TPD）と誘導ラマン散乱（stimulated Raman scattering、SRS）が作る高エネルギー電子を、較正した変換効率と温度で与える [2]。1D の輸送では、電子の運動を直線の弦に射影する。衝突で電子が減速し、射影した飛程が短くなる。外面のシースは電子を標的内に戻すことができる。TPD と SRS は、生成源の機構（捕獲する密度、温度、角度帯の既定値）の違いとして現れる。

扱わない効果。実装で確かめた範囲で、次のものは含まない。

  • TPD・SRS の波の成長と飽和。ホット電子の変換効率 η(t) は較正した入力で、eta_mode="model" を選んでも、局所のプラズマ量で駆動する縮約した緩和の式であり、波の方程式は解かない。
  • SRS・SBS（誘導ブリルアン散乱、stimulated Brillouin scattering）の後方散乱で失われる反射光。散乱光の反射率を与えるキーも、反射した光線を追跡する処理もない。CBET が SBS と同じ三波結合に基づくのは、相手のビームが種（seed）になる前方の交換に限る。
  • フィラメンテーション（filamentation）、自己集束（self-focusing）、スペックル（speckle）と波動光学（干渉、回折）。レーザーの経路は幾何光学の光線であり、コード内にこれらを扱う処理はない。
  • 既定の従来の縮約（geometry_mode="legacy"。ポート配置を使わず、二つの光線のあいだの方位角について平均する扱い）での、コースティック（caustic。光線の族の包絡線で、幾何光学の強度が発散する所 [3]）の近くの強度の補正。port_section（実際のポート配置を使う再構成）は、コースティックの近くの強度の上限と、コースティックの近くの寄与がある場合に保存の残差を減らすポンプ乗数を含む。どちらのモードも、コースティックの近くの波の場そのものは解かない。
  • スペックル統計、偏光のダイナミクス、広帯域の照射（CBET の頁に理由を書いている）。

結果は、指定した CBET 係数とホット電子の生成クロージャ（変換効率と温度）に対するプラズマの応答として読むこと。LPI の第一原理的な予測にはならない。

光線追跡との関係

CBET はレーザー駆動と吸収の光線追跡記録を使う。ホット電子は、動径吸収を含め、選択したレーザーの経路が作る捕獲記録を使う。

  • 受け取るもの（CBET）：光線が通ったセルごとの経路長と方向余弦、光線の初期パワー、ビームのグループ。これに加えて、流体の状態から、イオン温度、流速、平均質量数を読む。電子密度、電子温度、平均電離度は光線追跡が元から使う場である。
  • 受け取るもの（ホット電子） 生成源の位置と捕獲の規則が定めるパワーを受け取る。捕獲の密度は既定で臨界密度の 1/4 であり、SRS ではモデルモードで 0.20、従来モードで 0.18 である。通常の 1D 光線追跡の区間では捕獲までの IB 吸収を先に適用する。臨界密度に達する区間では入口のパワーを使う。radial_absorption_1d ではセル中点の密度を調べ、条件を満たす最初のセルの外面と、そのセルに入るパワーを使う。
  • 返すもの（CBET）：交換後の光線のパワー。その後の IB 沈着は、交換を済ませたパワーで計算する。離調があるときは、イオン音波へ渡したパワーの台帳 E_cbet_iaw も返す。
  • 返すもの（ホット電子） 既定の subtract_from_laser=True では捕獲したパワーを光線から差し引く。セルごとの付与をレーザーの沈着に加える。1D の輸送台帳は逸出・未解決・飛行中のエネルギーも記録する。

CBET とホット電子は、ふつう同じ実行で併用できない。併用できるのは、Laser.cbet.geometry_mode="port_section" と Laser.hot_electron.eta_mode="model" を同時に指定したときだけである。この組合せでは、ホット電子の捕獲が CBET の適用後の光線のパワーを使う。それ以外で両方を有効にすると、入力の検証がエラーで止める。この組合せを指定し、その時間刻みに捕獲チャネルがある場合に限り、光学側の検査は、光による付与パワー、未吸収光のパワー、捕獲したホット電子のパワー、イオン音波に渡したパワー、および CBET の交換残差の合計を入力レーザーパワーと比較する。これらの条件を満たさない 1D の時間刻みでは、CBET を使用していても通常のレーザー台帳を使う。この検査は、入力レーザーパワーから、付与パワー、未吸収光のパワー、ホット電子の逸出パワー、転送できなかったパワー、イオン音波に渡したパワー、および CBET の交換残差を差し引く。

演算子の列の中での位置

CBET もホット電子も、独立した演算子ではなく、レーザーの演算子の内部の段である。外側の 1 ステップの既定の列（Strang 型）では、レーザー、核燃焼、流体の前半、熱伝導、輻射、流体の後半の順に進む。レーザーの演算子は、光線の追跡、CBET の交換、ホット電子の捕獲・輸送・付与、そして IB の沈着とホット電子の付与パワーの電子エネルギーへの加算を含む。CBET とホット電子を併用するときは、初回の追跡も捕獲事象の位置で減耗を適用する。臨界密度に達する区間では事象までの光学的厚さを入口から 0 とする。CBET を解いた後の最終再計算で捕獲記録を輸送に渡す。列全体の分割の規律は演算子分割と再クロージャの規律にある。

陽的な源項の制限 "hot_electron" は、セルの電子エネルギーを付与パワーで割った値から次の時間刻み幅を制限する。1D では付与パワー、体積、密度、電子エネルギーが正のセルで最小値をとる。CBET とホット電子はいずれも単一の MPI ランクで実行する。

1D と 2D RZ の対応

効果1D（Main.dimension="1D_SPH"）2D RZ（"2D_RZ"）
CBETMesh.geometry_1d="spherical" と Laser.mode="raytrace_2d" が前提。geometry_mode="port_section"（単一の参照トレースを実際のポートの方向へ回転する再構成）か、従来形式の "legacy"（ビーム対の光線による交換。既定）を選べる。port_section は 1D 専用である。Laser.mode="raytrace_3d" が前提。"legacy" だけが使える。固定点反復の加速（anderson_depth）とワークスペースの上限（workspace_limit_gib）のキーは 2D 専用である。
ホット電子Laser.mode は "radial_absorption_1d" か "raytrace_2d"。角度分布は "cone"（既定）か "radial"。円筒幾何（Mesh.geometry_1d="cylindrical"）では "cone" を使えない。 平面円錐では planar_inner_face の明示が必要である。Laser.mode="raytrace_3d" が前提。角度分布は "cone" だけで、"radial" と inner_bc の変更は 1D 専用である。

詳細な式とアルゴリズムを子の頁が説明するのは、CBET では 1D の port_section、ホット電子では 1D と 2D RZ の両方である。2D RZ の CBET の従来形式は、子の頁には載せていない。
