LPI（レーザープラズマ相互作用）

レーザープラズマ相互作用（laser–plasma interaction、LPI）は、レーザー光とプラズマの波が結合して、逆制動輻射（inverse bremsstrahlung、IB）による吸収とは別の経路でエネルギーを移す過程の総称である。TENRYU が扱う LPI の効果は 2 つある。交差するビームのあいだでイオン音波（ion-acoustic wave）を介して光のパワーを移す交差ビームエネルギー転送（cross-beam energy transfer、CBET）と、四分の一臨界密度付近の不安定性が作るホット電子（hot electron）の生成、輸送、物質へのエネルギー付与である。どちらも光線追跡の上に載るカーネルで、光線が運ぶパワーを受け取って書き換え、結果をレーザーの沈着として物質に返す。波の成長や飽和、後方散乱（backscatter）の反射光は解かない。この頁は 2 つの効果の位置づけ、光線追跡との受け渡し、演算子の列の中での位置、1D と 2D RZ の対応、入口となるキーを説明する。各効果の式とアルゴリズムは子の頁で説明する。

CBET

交差するビームのあいだで、イオン音波を介して光のパワーを移す保存型の交換。ポートの配置と波長離調を扱う。

ホット電子

較正した変換効率とスペクトルによる、ホット電子の生成、直線輸送、予熱の付与。

扱う効果と扱わない効果

扱う効果。CBET とホット電子の 2 つである。

  • CBET：2 本のビームのビートがポンデロモーティブ力（ponderomotive force）でイオン音波を駆動し、その音波を介して一方のビームから他方へパワーが移る。TENRYU は、線形・定常・強減衰（strongly damped）の局所平面波の利得 [1] でこの交換を評価し、1 回の交換でパワーの総和を保つ。波長離調（wavelength detuning）があるときは、イオン音波へ渡したパワーを符号付きの台帳 E_cbet_iaw に記録する。
  • ホット電子：2 プラズモン崩壊（two-plasmon decay、TPD）と誘導ラマン散乱（stimulated Raman scattering、SRS）が作る高エネルギー電子を、較正した変換効率と温度で与える [2]。生成した電子は直線に沿って輸送し、衝突による減速で失ったエネルギーを物質へ付与する。TPD と SRS は、生成源の機構（捕獲する密度、温度、角度帯の既定値）の違いとして現れる。

扱わない効果。実装で確かめた範囲で、次のものは含まない。

  • TPD・SRS の波の成長と飽和。ホット電子の変換効率 η(t) は較正した入力で、eta_mode="model" を選んでも、局所のプラズマ量で駆動する縮約した緩和の式であり、波の方程式は解かない。
  • SRS・SBS（誘導ブリルアン散乱、stimulated Brillouin scattering）の後方散乱で失われる反射光。散乱光の反射率を与えるキーも、反射した光線を追跡する処理もない。CBET が SBS と同じ三波結合に基づくのは、相手のビームが種（seed）になる前方の交換に限る。
  • フィラメンテーション（filamentation）、自己集束（self-focusing）、スペックル（speckle）と波動光学（干渉、回折）。レーザーの経路は幾何光学の光線であり、コード内にこれらを扱う処理はない。
  • CBET の火面（caustic）補正、スペックル統計、偏光のダイナミクス、広帯域の照射（CBET の頁に理由を書いている）。

結果は、指定した CBET 係数とホット電子の生成クロージャ（変換効率と温度）に対するプラズマの応答として読むこと。LPI の第一原理的な予測にはならない。

光線追跡との関係

CBET もホット電子も、レーザー駆動と吸収の頁の光線追跡が作る光線の記録を入力にする。独立の光線を別に追跡するのではない。

  • 受け取るもの（CBET）：光線が通ったセルごとの経路長と方向余弦、光線の初期パワー、ビームのグループ。これに加えて、流体の状態から、イオン温度、流速、平均質量数を読む。電子密度、電子温度、平均電離度は光線追跡が元から使う場である。
  • 受け取るもの（ホット電子）：追跡した各光線が、電子密度が臨界密度の指定した割合（捕獲面。既定は 1/4）に初めて達する点と、その点まで IB 吸収を生き延びたパワー。
  • 返すもの（CBET）：交換後の光線のパワー。その後の IB 沈着は、交換を済ませたパワーで計算する。離調があるときは、イオン音波へ渡したパワーの台帳 E_cbet_iaw も返す。
  • 返すもの（ホット電子）：捕獲したパワーを光線のパワーから差し引いた残り（既定の subtract_from_laser=True）と、セルごとのホット電子の付与パワー。付与パワーは、レーザーの沈着パワーに加算して電子の内部エネルギーへ入る。メッシュの外へ逃げた分は、エネルギー台帳ではレーザーの逸出に数える。

CBET とホット電子は、ふつう同じ実行で併用できない。併用できるのは、Laser.cbet.geometry_mode="port_section" と Laser.hot_electron.eta_mode="model" を同時に指定したときだけである。この組合せでは、ホット電子の捕獲が CBET の適用後の光線のパワーを使う。それ以外で両方を有効にすると、入力の検証がエラーで止める。

演算子の列の中での位置

CBET もホット電子も、独立した演算子ではなく、レーザーの演算子の内部の段である。外側の 1 ステップの既定の列（Strang 型）では、レーザー、核燃焼、流体の前半、熱伝導、輻射、流体の後半の順に進む。レーザーの演算子は、光線の追跡、CBET の交換、ホット電子の捕獲・輸送・付与、そして IB の沈着とホット電子の付与パワーの電子エネルギーへの加算を含む。ホット電子の捕獲は光線の追跡の途中で行い、CBET と併用する組合せでは CBET を解いたあとで行う。列全体の分割の規律は演算子分割と再クロージャの規律にある。

ホット電子の付与は陽的な源項なので、時間刻みの制限 "hot_electron" が次のステップの Δt を、付与パワーとセルの電子エネルギーの蓄えの比で制限する。CBET もホット電子も、単一の MPI ランクでしか動作しない。

1D と 2D RZ の対応

効果1D（Main.dimension="1D_SPH"）2D RZ（"2D_RZ"）
CBETMesh.geometry_1d="spherical" と Laser.mode="raytrace_2d" が前提。geometry_mode="port_section"（単一の参照トレースを実際のポートの方向へ回転する再構成）か、従来形式の "legacy"（ビーム対の光線による交換。既定）を選べる。port_section は 1D 専用である。Laser.mode="raytrace_3d" が前提。"legacy" だけが使える。固定点反復の加速（anderson_depth）とワークスペースの上限（workspace_limit_gib）のキーは 2D 専用である。
ホット電子Laser.mode は "radial_absorption_1d" か "raytrace_2d"。角度分布は "cone"（既定）か "radial"。円筒幾何（Mesh.geometry_1d="cylindrical"）では "cone" を使えない。Laser.mode="raytrace_3d" が前提。角度分布は "cone" だけで、"radial" と inner_bc の変更は 1D 専用である。

詳細な式とアルゴリズムを子の頁が説明するのは、CBET では 1D の port_section、ホット電子では 1D と 2D RZ の両方である。2D RZ の CBET の従来形式は、子の頁には載せていない。
