空間離散化

電子熱伝導の空間離散化は、1D では保存型の有限体積（finite-volume）演算子、2D RZ では対称なコンダクタンスをもつ節点局所の演算子（node-local operator）である。この頁は、1D の面の伝導率の作り方（face-κ policy）、2D RZ の節点局所の演算子、材料別の保存モード（per-material conservation mode）、ボイド（void）セルの扱いを定義する。

この計算で使う用語

空間離散化には、TENRYU の実装に固有の意味で使う語がある。1D の面の伝導率の作り方、2D RZ の節点局所の演算子、材料別の保存モードである。これらをまとめて定義する。スーパータイムステッピングの時間刻みを表す語は時間積分の頁、SNB の量はSNB の頁にある。

面の伝導率の作り方

面の伝導率の作り方（face-κ policy）は、1D で、隣り合う 2 つのセルの κ から、その境にある面の熱伝導率 \(\kappa_f\) を決める規則である。キーは Numerics.conduction.face_kappa_policy で、値は "kirchhoff_same_material"（既定）と "harmonic" である。

\(\kappa\propto T^{5/2}\) は、急峻な熱波面（thermal wave front）を横切る温度区間で何桁も変わる。そのため \(\kappa_f\) の作り方が、波面の進み方を左右する。"harmonic" は、左右のセル幅 \(w_L,w_R\) で重み付けした調和平均（width-weighted harmonic mean）\((w_L+w_R)/(w_L/\kappa_L+w_R/\kappa_R)\)（等間隔格子では \(2\kappa_L\kappa_R/(\kappa_L+\kappa_R)\)）を \(\kappa_f\) とする。調和平均は小さい方の κ に引かれるので、波面の前方では \(\kappa_f\) が過小になり、波面が格子に固着しがちである。片側の κ が正でない、またはボイドのときは \(\kappa_f=0\) で、熱は通らない。

"kirchhoff_same_material" は、左右の温度 \(T_L\)、\(T_R\) の区間で \(T^{5/2}\) を厳密に積分した割線（secant）に、左右の基底係数の幅重み付き調和平均を掛ける。Kirchhoff 変換（Kirchhoff transformation）に基づく面平均である。

$$ \kappa_f=\tilde\kappa_f\,\frac27\,\frac{T_R^{7/2}-T_L^{7/2}}{T_R-T_L},\qquad \tilde\kappa_f=\frac{w_L+w_R}{w_L/\tilde\kappa_L+w_R/\tilde\kappa_R},\qquad \tilde\kappa=\frac{\kappa}{T^{5/2}}. $$

ここで \(\tilde\kappa\) は、セルの κ から取り出した Spitzer 前置因子、\(w_L,w_R\) は面を挟む左右セルの幅である。1D では物質界面を含む両側が有効なすべての面にこの割線式を適用する（値の名前 "kirchhoff_same_material" は互換性のため維持している）。\(|T_R-T_L|/T_m\lt 10^{-4}\)（\(T_m=(T_L+T_R)/2\)）では桁落ちを避けるため中点展開の 2 次近似を用い、片側がボイドまたは \(\rho c_v\le0\) か κ が正でないときは \(\kappa_f=0\) とする。\(\kappa_f\) は、流束制限に使う SH の推定値、実際の流束、および 1D の \(\Delta t_{exp}\) の面コンダクタンス上界（手順 3）に共通して用い、1D の電子 STS では各 RKL2 段で評価し直す。

2D RZ は節点局所の演算子（次項）を使い、面の \(\kappa_f\) を作らない。このキーは、演算子の各対に、2 つのセルの温度による割線（上の式の \(\tfrac27(T_R^{7/2}-T_L^{7/2})/(T_R-T_L)\)）を掛けるかどうかだけを選ぶ。"kirchhoff_same_material" では掛け、"harmonic" では掛けない。SNB の 2D RZ は割線を使わない。

節点局所の演算子

節点局所の演算子（node-local operator）は、2D RZ の熱伝導（電子、イオン、SNB の各群の方程式）で、セル中心の温度どうしを結ぶ対称な線形演算子である。2D RZ のメッシュは、子午面（meridional plane。r–z 面）の多角形のセルから成る。演算子は節点ごとの寄与の和で、節点の寄与は次のように作る。

コーナー（corner）は、節点 \(p\) に集まるセルのそれぞれについて、セルのうち \(p\) に接する部分である。セルの基準点（凸なセルでは重心）、\(p\) の前の辺の中点、\(p\)、\(p\) の後の辺の中点を結ぶ四角形で、流体の頁のコーナーと同じ分割である。

半辺（half-edge）は、\(p\) から出る各辺を中点で 2 つに分けたもののうち、\(p\) 側の部分である。半辺の温度 \(\Theta\) は未知数で、その半辺をはさむ 2 つのコーナー（境界では 1 つ）が共有する。各コーナーの温度勾配を、セルの温度と半辺の温度から Green–Gauss の式で表し、半辺を通る熱流を求める。内部の半辺では両側の熱流が等しく、境界の半辺では熱流が 0 であるという条件から、\(\Theta\) を節点を共有するセルの温度で表して消去する。残るのが、セル \(c\) から出る熱を、節点を共有するセルの温度の線形結合で表す行列 \(a\) である。

行列 \(a\) の行と列の和はどちらも 0 で（一様な温度に熱流はなく、熱流は連続である）、\(a\) は対称半正定値（symmetric positive semidefinite）である。セル \(c\) と、節点を共有するセル \(d\) の対の係数を \(G_{cd}=-(a_{cd}+a_{dc})/2\) とすると、セル \(c\) の熱容量 \((\rho c_vV)_c\) と温度の変化率の積は、隣のセルから流れ込む熱の和に等しい（\(V\) は回転体としての体積）。

$$ (\rho c_vV)_c\,\frac{dT_{e,c}}{dt}=\sum_dG_{cd}\,(T_{e,d}-T_{e,c}). $$

割線を使うときは、右辺の各項に \(S_{cd}\) を掛ける（手順 6）。\(G_{cd}=G_{dc}\) なので、対の電力 \(G_{cd}(T_d-T_c)\) はセル \(c\) と \(d\) で符号だけが違い、熱エネルギーは保存される。

この演算子はメッシュの添字 \((i,j)\) を使わないので、四角形でないセルや、複数のブロックから成るメッシュにも同じ手順で使える。異なる伝導率のセルのあいだの熱流は、半辺での熱流の連続から決まり、面の調和平均は使わない。境界の半辺の熱流は 0 である。ただし、状態供給（state_supply）が働く z_bottom と z_top の側の半辺は、供給温度に保つ（単一ブロックのメッシュ）。演算子を選ぶキーはなく、2D RZ の熱伝導はすべてこの演算子で解く。対の係数 \(G_{cd}\) が、STS の更新と、陽的な安定限界 \(\Delta t_{exp}\) の上界を決める。

材料別の保存モード

材料別の保存モード（per-material conservation mode）は、1 つのセルに複数の材料が混在するとき、材料ごとの質量、体積率（volume fraction）、電子エネルギーを状態として持ち、材料ごとのエネルギーを保存する設定である。材料ごとの EOS で、材料ごとの温度と圧力を扱うために使う。キーは Numerics.materials.per_material_conservation_enabled（既定 False、2D RZ のみ）である。混合セル（mixed cell）の扱いは Numerics.materials.mixed_cell_closure で選ぶ。既定の "equal_compressibility" は、体積率を固定し、セルの圧力を材料の圧力の体積率による和とする扱いである。"pressure_relaxation" は、材料の圧力を、速度を制限して緩和させる扱いである。

熱伝導では、セルの電子温度を 1 つだけ STS で進め、そのエネルギーの変化を材料に配る。配り方は面の伝導率の節にある。SNB とは併用できない（入力検査が拒否する）。2D RZ でイオン熱伝導と併用するときは、mixed_cell_closure="pressure_relaxation" が要る。

面の伝導率、材料別の保存モード、ボイド

1D の面の κ の作り方（定義と式は用語の節）は、既定の kirchhoff_same_material では、物質界面を含む両側が有効なすべての面に幅重み付き調和平均の基底係数と Kirchhoff 割線の積を使う。単純な両端評価では急峻な熱波面の前面で面 κ が過小になり、波面が格子に固着しがちだが、割線はこの傾向を弱め、幅重み付けによってセル幅が異なる物質界面でも 2 次精度を保つ。harmonic も選べ、セル伝導率の幅重み付き調和平均を用いる — 調和平均なので、片側の κ が 0 なら面の流束も 0 である。流束制限に使う SH の推定値と実際の流束は必ず同じ面の κ を使い、1D の電子 STS では RKL2 の各段でこれらを評価し直す。

2D RZ には面の κ がない。異なる伝導率のセルのあいだの熱流は、半辺での熱流の連続から決まり、調和平均は使わない。face_kappa_policy は、節点局所の演算子の各対に、その 2 つのセルの温度による割線を掛けるかどうかだけを選ぶ。

1D の平面・円筒・球の演算子は保存型の有限体積で、幾何の違いは面積 \(A_f\) とセル体積 \(V_i\) にしか現れない。材料別の保存モード（定義は用語の節、2D RZ のみ）では、セルごとに電子温度を 1 つだけ STS で進め、そのエネルギー変化を材料に配る。セルの伝導率は、材料 \(m\) ごとにその温度、密度、\(\bar Z\)、lnΛ から作った制限済みの熱伝導率 κeff,m を、体積率 αm で重み付けて足した和 Σmαmκeff,m とする。

全段を終えたあと、セル \(c\) の電子エネルギーの変化 \(\Delta E_c=(\rho c_vV)_c(T_c^{n+1}-T_c^n)\) を、次の規則で材料に配る。\(\Delta E_c>0\) は、ステップ入口の材料の電子熱容量に比例して配り、各材料の温度が同じだけ上がるようにする。\(\Delta E_c<0\) は、材料の電子エネルギーの、温度の床（floor。Numerics.floors.Te。定義）における状態からの余剰に比例して配る。余剰の合計が \(-\Delta E_c\) に足りないときは、全材料が床の状態になり、不足分は床で加えたエネルギーとしてエネルギー台帳（energy ledger）に載せる。余剰が足りるときは、材料の電子エネルギーの和の変化がセルの変化に丸め誤差の範囲で一致する。mixed_cell_closure="pressure_relaxation" のときは、伝導は材料を区別しないセルの係数で進み、エネルギーの材料への配分はドライバが混合セルの圧力緩和の規則で行う。

cell_is_void のセルでは κeff=0 を強制する。これによりボイドの境界は熱を通さない断熱面になる。このマスクは性能の面でも必要である。下限密度しかもたないボイドのセルを通常の物質として評価すると、拡散率 κ/(ρcv) の分母が極端に小さいために巨大な拡散係数が生じ、それが安定限界 Δtexp を潰して STS を実質的に止めてしまうからである。SNB でも同じ扱いを徹底する。ボイドのセルは Hg=0 の恒等行とし、隣接面の群拡散係数を 0 にして、群拡散がボイドを飛び越えて予熱を運ぶ経路を残さない。

検証

  • Kirchhoff 割線と流束制限の検査：1D の面伝導率方針の検証（test_conduction_face_kappa_policy_1d）は、一様温度での不変性、急峻な面における Kirchhoff 割線による流束の固着解消、近接温度での有限性と保存性、および陰解法（solver="implicit"）が指定された face_kappa_policy を反映し 2 方針で異なる温度解を与え、Kirchhoff 割線側でエネルギーを保存することを検査する。別途、流束制限と方針の一貫性試験（test_conduction_limiter_policy_consistency）が、流束制限が効いた状態での \(|q|\le q_{max}\) の成立と、Gershgorin 上界による時間刻み保護（体積 0 のセルは除外）を検査する。
  • 不均一セル幅の物質界面（2 物質接触）：1D 熱伝導の解析解による検証の頁で、幅比 4 の DT–Au–DT 界面における空間 2 次収束（観測次数 2.06・2.05）を判定する。
