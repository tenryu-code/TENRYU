核燃焼 reference

TENRYU の燃焼カーネル（中核は 1D 球対称で、2D RZ では scheme="local" と "diffusion" が使える）は、Bosch–Hale による DT・DD・D³He の反応率、燃料の減損（depletion）、荷電生成物の沈着または輸送、電子とイオンへのエネルギー分配を、ひとつの陽的な源（explicit source）の段階（stage）としてまとめて進める。このほか、遮蔽効果（screening）、多群拡散（multigroup diffusion）とモンテカルロ（Monte Carlo）による荷電生成物の輸送、2 本の線スペクトル（line spectrum）による初回衝突（first collision）の中性子加熱も扱う。この頁は燃焼全体の物理機構と 1 回の段階の手順を述べ、項目ごとの詳細は下の 3 頁に分けて書く。この計算に固有の用語は、各頁の用語の節で説明する。

要点

  • 既定では無効である。中核は 1D_SPH の球面ラグランジュセルで、2D RZ への移植では scheme="local" と "diffusion" だけが使える。"fraley" の点源球の核（用語）は 1D 固有、"mc" は未移植、中性子加熱（neutron_heating）は 1D 専用なので、2D では設定検証が拒否する。scheme の既定値は "fraley" なので、2D では scheme を省略できず、"local" か "diffusion" を明示する。
  • 在庫（inventory。セルごとの核種の粒子数）は密度ではなく比在庫（specific inventory）\(Y_s=n_s/\rho\) [1/g] で保持し、膨張・圧縮にともなう希釈を自動的に扱う（在庫と比在庫）。
  • scheme は荷電生成物の扱いを選ぶ。中性子加熱は、これとは別の neutron_heating で有効にする。
  • 核融合で解放された静止質量エネルギーは外部からの源としてエネルギー台帳（energy ledger）に記帳し、沈着分・逸出分・飛行中のエネルギーを別々に監査する（飛行中と燃焼の台帳）。

物理機構

燃焼の段階は、核融合の静止質量を高速の荷電生成物と中性子へ変換する。2 温度（two-temperature）のラグランジュ計算では、カーネルが Bosch–Hale の反応率係数（reactivity）による、反応チャネル（reaction channel）ごとの反応率 \(n_i n_j\langle\sigma v\rangle/(1+\delta_{ij})\) を進め、燃料を減らし、解放されたエネルギーを電子とイオンの加熱源として返す。在庫は、ラグランジュ的な不変量である比在庫 \(Y_s=n_s/\rho\) として保持する。圧縮は \(\rho\) を通してのみ \(n_s\) を変えるため、流体計算が粒子を生成したり消滅させたりすることはない。比在庫で保持することで、生成時の密度を持ち越して膨張するセルを過剰に燃やす不具合を避けられる。

荷電生成物の輸送が重要なのは、3.5 MeV の α 粒子の飛程が面密度（areal density）で決まり、そのエネルギーがホットスポット（hot spot）の中に残るか外へ逃げるかで、自己加熱（self-heating）と点火余裕（ignition margin）が変わるためである。TENRYU は、意図的に階層をなす 3 つのモデルを用意している。Fraley の点源球（point-source sphere）[1] は、球幾何における局所の保持率を安価に解析的に求める（点源球の核と保持率）。多群拡散（multigroup diffusion）は、Corman らの多群方程式を、下端 diffusion_E_min_keV、上端 15.5 MeV の対数等間隔のエネルギー格子の上で解き、6 種類の生成物を、統計的なゆらぎなしに減速させる。モンテカルロ（Monte Carlo）の連続減速近似（continuous slowing-down approximation、CSDA）は、直線的に進む粒子をステップをまたいで保持する、統計的な参照解である。3 方式はいずれも同じエネルギー台帳へ報告する。

高速のイオンは、エネルギーが高いうちは主にプラズマ中の電子へエネルギーを失い、減速して臨界エネルギー（critical energy。電子への損失とイオンへの損失がちょうど等しくなるエネルギー）を下回ると、イオンへの損失が支配的になる。この分配が重要なのは、イオンの加熱が次の燃焼を促す一方、電子の加熱は熱伝導と輻射へ漏れ得るからである。既定の Li–Petrasso の阻止能（stopping power）[2] に基づく分配は、初期化時に \(T_e,T_i,n_e\) の表にし、実行中は補間だけを行う。イオンへ渡るエネルギーの割合を \(f_i=1/(1+32/T_e[\mathrm{keV}])\) とする、より単純な Fraley の式 [1] は、DT の α 粒子に対してのみ残している。

中性子加熱のモデルは、燃料中の D/T に対する単一飛行・初回衝突の反跳（recoil）加熱で、14.049 MeV と 2.449 MeV の離散的な 2 本の線を使う。最初の衝突で平均の反跳エネルギーをその場に付与し、同じ Li–Petrasso の表で電子とイオンへ分配する。2 回目以降の飛行、カーマ（kerma。中性子相互作用が単位質量あたりに物質へ放出する運動エネルギー）、(n,2n) 反応、飛行時間（time of flight）、スペクトルの幅は明示的に省いているため、得られる分布は中性子輸送の解ではなく、燃料の自己加熱の近似である。Salpeter の 2 温度形 [3]（用語）と Chugunov–DeWitt の遮蔽オプション [4] は、低温での反応率係数を変更する。Salpeter の 2 温度化は TENRYU による拡張である。核融合のエネルギーは外部からの静止質量の源として、沈着分・逸出分・飛行中の分に分けて監査する。

1 回の燃焼段階の手順

  1. 燃焼の段階のあいだ、各セルの密度と電子・イオン温度を一定に保つ。
  2. 有効なチャネルの反応率を計算し、2 次ルンゲ–クッタ（RK2）に必要な部分サイクルの数を各反応物の総生成率と総消費率から決めて、1 部分サイクルあたりの相対的な在庫変化を eps_deplete 以下に抑える。正味の変化ではなく総量を使うことで、微量の T が DD で生成され DT で消費される回転を解像できる。
  3. 5 核種のネットワークを陽的中点法で進める。提案された反応回数が反応物を使い切ってしまう場合は、在庫を再構成する前に回数を決定論的に縮小し、正値性と化学量論（stoichiometry）の収支を保つ。
  4. 必要な部分サイクルの数が subcycle_max に張り付いた場合は報告し、\(0.9\,dt\,M_{max}/M_{req}\) を次の燃焼の時間刻みの制限へ反映させる。これとは独立に、沈着する源のパワーに対して \(\Delta t\le f_E e_{cell}/P_{dep}\) を課す。
  5. 荷電生成物を、選択した方式（1D は fraley、diffusion、mc、2D RZ は local、diffusion）へ渡し、中性子は任意選択の初回衝突加熱の経路（1D 専用）へ渡す。
  6. 沈着したエネルギーを電子とイオンの源へ分配し、燃焼の台帳（沈着・逸出・飛行中）を更新して、まとめた燃焼の時間刻み制限をドライバへ渡す。

namelist による制御

以下は最上位の Burn ブロックのうち、燃焼全体に関わるキーである。ほかのキーは、そのキーを説明する頁の表にある（反応率と燃料の減損、荷電生成物の輸送と付与、中性子加熱）。検証規則の全体は namelist リファレンスを参照のこと。表の既定値は、デッキで指定しないときの値である。Studio が書き出す既定値も同じだが、fuel_materials は Studio では空で、利用者が指定する。Studio は燃焼を 1D 球対称の計算にだけ許し、fraley、diffusion、mc を書き出す。

キー既定値用途
enabledFalse燃焼全体の有効化スイッチ。1D では球面幾何が必須、2D RZ では scheme="local"/"diffusion" のみ有効である。
fuels["DT","DD"]DT、DD、D3He から反応チャネルを選択。

検証

  • 機能を無効にした実行と基準の実行との A/B 対比較では、場が 53/53、履歴が 164/164 でビット単位に一致し、GXII（激光 XII 号、GEKKO XII）の基準解でも相対差 0 を 6 回確認した。燃焼段階の台帳の検査と、多群拡散・モンテカルロの輸送の検査は、「解放 = 沈着 + 逸出 + 飛行中の変化」という台帳の恒等式を、丸め誤差の範囲で課す。
