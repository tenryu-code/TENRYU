2D RZ メッシュ: 構造格子とマルチブロック reference

2D では、構造矩形、球面極座標、箱の中の極座標、そして CSR 接続によるマルチブロックの各系統を、同じ RZ 幾何の契約へ写像する。

物理機構

矩形、極座標、箱の中の極座標、シェルと襟のマルチブロック、五角形帯のいずれの 2D 系統であっても、物理へ渡すものは同じでなければならない。すなわち、回転体としての RZ セル体積、正確なコーナーの幾何、そして節点・セル・面の一貫した接続関係である。物理カーネルは、どの生成器がメッシュを作ったかを知らない。これが「RZ 幾何の契約はひとつ」という言い方の意味であり、問題ごとに系統を差し替えられる理由でもある。

各系統は、それぞれ異なる幾何の問題を解く。矩形 RZ は頑健な既定であり、極座標は球状の収束に沿い、球状の収束流では質量流束が立体角に比例するため、等立体角の分割は各角度リングの担う質量流束を均等にする。箱の中の極座標は、球形の標的と矩形の外周を両立させる。シェルと襟からなるマルチブロックの組み立ては、実際の標的の構造に沿う。極座標の中心近傍では、五角形の帯が角度分割数の変化を接続関係の側へ吸収する。中心に近づくと角度方向のセル幅が縮み、軸近傍に細長いセルが生じる。この細長化は節点の平滑化では解消できず、角度の分割数そのものを途中で減らす必要がある。入れ子になった 2:1 の段列の上に置く 5 辺の遷移セルが、退化した TWO_TO_ONE の接合（粗いセルの辺の上に細かい側の節点が乗る形の 2:1 接合）を置き換え、この切替を正規の多角形セルとして扱う。

メッシュの品質は見栄えの指標ではなく、許容されるための条件である。最小高さとコーナーのヤコビアンは、体積・力・リマップの各演算子が必要とする不変量である。このため保護判定は、時間刻みを予測的に制限したり、候補となる状態を拒否したりすることがある。生成器も、向きや体積が正であるという契約を守れないメッシュは返さず、明示的に失敗する。

  • 接続関係: 単一ブロックの構造格子セルは、暗黙の 4 コーナーの添字付けを使う。マルチブロックの系統は CSR 形式のセル→節点、逆向きの節点→セル、面の隣接関係を使い、各接合部では単一の所有側が書き込む共有の節点 ID を共有する。
  • コーナーの容量: 通常の四辺形の配置では corner_stride=4、五角形帯の方式では corner_stride=8 を使い、cell_nverts が有効な枠の数を指定する。
  • 極座標の切り詰め: polar_theta_min が正のとき、切断する半直線が鏡映境界になり、反対側の辺は \(R=0\) の軸へ厳密に合わせられる。
  • 等 \(\mu\) 分割: polar_equal_mu_zoning は角度方向の節点を \(\mu=\cos\theta\) について等間隔に配置し、\(\theta\) 等間隔ではなく等立体角を与える。

2D RZ の構造的な配置

2D の既定である logical_mesh_2d="rectangular_rz" は、\(N_rN_z\) 個の四辺形セルと \((N_r+1)(N_z+1)\) 個の節点をもつ行優先の構造格子である。セル \((i,j)\) は 4 つの節点 \((i,j),(i+1,j),(i+1,j+1),(i,j+1)\) に囲まれ、熱力学量をセルに、位置と速度を節点に置く。断面上の四辺形は方位角方向へ回転させた RZ 体積として評価するため、単なる平面の面積ではない。ラグランジュ運動や ALE のリゾーンで物理座標が動いても、単一ブロックにおける論理的な \((i,j)\) の接続は変わらない。

極座標とマルチブロックの系統

構造化された極座標メッシュは \((s,\theta)\mapsto(R,Z)=(s\sin\theta,s\cos\theta)\) によって半平面へ写像する。\(\theta\) は一様、区間ごとの指定、または polar_equal_mu_zoning による等立体角の配置から選べる。polar_theta_min>0 は三角形扇のメッシュを \([\theta_{\min},\pi]\) に切り、切断する半直線を鏡映境界、その反対側を厳密な \(R=0\) の軸とする。半径座標の下限を正に取り内側に核領域を残すものが環状、内側のリング群を単一の中心セルに置き換えて原点まで能動にするものがボタンである。箱の中の極座標は、内側の極座標部分を滑らかに矩形の外周へ変形させ、箱に沿う襟状のリングで閉じる。物体に沿ったシェルと襟の組み立て（コーンのような、截断円錐殻の壁を持つ実標的を想定した系統）は、殻の壁、壁近傍の帯、充填ガスを、隙間のないブロックとして組み合わせる。中心側で角度分割数を変える五角形帯の接続は、一般的な TWO_TO_ONE の接合の代わりに 5 頂点の遷移セルを置き、細かい \(\theta\) の段列を 2:1 で間引く。構造格子が暗黙の 4 コーナーの添字付けを使うのに対し、マルチブロックはセル→節点、逆向きの節点→セル、面の隣接関係を CSR 形式で保持し、接合部の節点は単一の所有側がもつ共有 ID になる。各セルは cell_nverts として有効な頂点数をもち、通常は corner_stride=4、五角形帯における多角形の容量は corner_stride=8 である。各生成器が段階ごとに対応する物理と制約は namelist リファレンスに従う。

namelist から受理されたメッシュまで

  1. 選択と検証。 メッシュの系統を選び、半径方向・軸方向・角度方向のうち該当する区間の数と端点を検証する。

  2. 節点を生成する。 該当する一様・傾斜配置・等 \(\mu\) の段列を構築し、必要な軸上の節点を厳密に \(R=0\) へ合わせる。

  3. 接続関係を組み立てる。 構造ブロックでは暗黙の添字付けを、マルチブロックのセルでは CSR の接続を使い、共有される接合部の節点について所有側を明示する。

  4. セルを検査する。 メッシュを次の段へ渡す前に、向きと、厳密な回転体としての RZ 体積が正であることを検証する。

  5. コーナーの幾何を保持する。 エネルギー整合な演算子（流体）と品質検査が使うコーナー面積ベクトル \(\mathbf S\) と、最小高さのデータを構築する。

  6. 流体へ引き渡す。 共通の幾何・接続の契約を公開し、予測的な最小高さの保護判定と、コーナーヤコビアンの保護判定を有効にする。

選択に関わるキー

以下は、メッシュとデッキ側の幾何に関する代表的な入口である。検証規則の全体と段階ごとの対応範囲は namelist リファレンスを参照のこと。

キー対象用途
Mesh.nr, nz, logical_mesh_2d2D論理的な解像度と、rectangular_rz、spherical_polar_halfplane、polar_in_box、cone_shell の選択。
Mesh.grid_r, grid_z, grid_theta2D方向ごとの一様・傾斜配置の区間。極座標の θ 区間は、材料や壁の境界を面に合わせて固定できる。
Mesh.polar_equal_mu_zoning2D 極座標一様な θ の代わりに、等立体角の節点を生成する。
Mesh.polar_theta_min2D 極座標既定は 0。正の値では三角形扇の範囲を \([\theta_{\min},\pi]\) に切断する。

検証

  • test_mesh_quality_dt_limiter と流体内での保護判定の試験は、最小高さとコーナー \(J\) の下限、膨張時には制限しないこと、反転する候補を拒否すること、そして決定論性を検査する。
  • test_polar_truncated_span は、\(\theta_{\min}\) からの開始、鏡映による切断、体積が正であること、解析的なくさび体積、閉じた中心の扇、ビット単位の決定性を固定する。
  • test_h02_axis_exact_snap は、環状・三角形扇・ボタンのいずれについても両極の行が厳密に \(R=0\) となり、赤道と南北の鏡映が必要な経路で厳密になることを検査する。
  • マルチブロックの接続に関する試験は、接合部で共有される節点 ID、CSR の面隣接関係の対における双方向・相互の整合性、逆向きの接続、五角形帯における頂点数・向き・2:1 の θ の入れ子を検査する。
