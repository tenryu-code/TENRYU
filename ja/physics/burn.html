核燃焼 reference

TENRYU の 1D 球対称の燃焼カーネルは、Bosch–Hale による DT・DD・D³He の反応率、燃料の減損（depletion）、荷電生成物の沈着または輸送、電子とイオンへのエネルギー分配を、ひとつの陽的な源（explicit source）の段階（stage）としてまとめて進める。このほか、遮蔽効果（screening）、多群拡散（multigroup diffusion）とモンテカルロ（Monte Carlo）による荷電生成物の輸送、2 本の線スペクトル（line spectrum）による初回衝突（first collision）の中性子加熱も扱う。この計算に固有の用語は用語の節で説明する。

要点

  • 既定では無効である。中核は 1D_SPH の球面ラグランジュセルで、2D RZ への移植では scheme="local" と "diffusion" だけが使える。"fraley" の点源球の核（用語）は 1D 固有、"mc" は未移植、中性子加熱（neutron_heating）は 1D 専用なので、2D では設定検証が拒否する。scheme の既定値は "fraley" なので、2D では scheme を省略できず、"local" か "diffusion" を明示する。
  • 在庫（inventory。セルごとの核種の粒子数）は密度ではなく比在庫（specific inventory）\(Y_s=n_s/\rho\) [1/g] で保持し、膨張・圧縮にともなう希釈を自動的に扱う（在庫と比在庫）。
  • scheme は荷電生成物の扱いを選ぶ。中性子加熱は、これとは別の neutron_heating で有効にする。
  • 核融合で解放された静止質量エネルギーは外部からの源としてエネルギー台帳（energy ledger）に記帳し、沈着分・逸出分・飛行中のエネルギーを別々に監査する（飛行中と燃焼の台帳）。

物理機構

燃焼の段階は、核融合の静止質量を高速の荷電生成物と中性子へ変換する。2 温度（two-temperature）のラグランジュ計算では、カーネルが Bosch–Hale の反応率係数（reactivity）による、反応チャネル（reaction channel）ごとの反応率 \(n_i n_j\langle\sigma v\rangle/(1+\delta_{ij})\) を進め、燃料を減らし、解放されたエネルギーを電子とイオンの加熱源として返す。在庫は、ラグランジュ的な不変量である比在庫 \(Y_s=n_s/\rho\) として保持する。圧縮は \(\rho\) を通してのみ \(n_s\) を変えるため、流体計算が粒子を生成したり消滅させたりすることはない。比在庫で保持することで、生成時の密度を持ち越して膨張するセルを過剰に燃やす不具合を避けられる。

荷電生成物の輸送が重要なのは、3.5 MeV の α 粒子の飛程が面密度（areal density）で決まり、そのエネルギーがホットスポット（hot spot）の中に残るか外へ逃げるかで、自己加熱（self-heating）と点火余裕（ignition margin）が変わるためである。TENRYU は、意図的に階層をなす 3 つのモデルを用意している。Fraley の点源球（point-source sphere）[4] は、球幾何における局所の保持率を安価に解析的に求める（点源球の核と保持率）。多群拡散（multigroup diffusion）は、Corman らの多群方程式を、下端 diffusion_E_min_keV、上端 15.5 MeV の対数等間隔のエネルギー格子の上で解き、6 種類の生成物を、統計的なゆらぎなしに減速させる。モンテカルロ（Monte Carlo）の連続減速近似（continuous slowing-down approximation、CSDA）は、直線的に進む粒子をステップをまたいで保持する、統計的な参照解である。3 方式はいずれも同じエネルギー台帳へ報告する。

高速のイオンは、エネルギーが高いうちは主にプラズマ中の電子へエネルギーを失い、減速して臨界エネルギー（critical energy。電子への損失とイオンへの損失がちょうど等しくなるエネルギー）を下回ると、イオンへの損失が支配的になる。この分配が重要なのは、イオンの加熱が次の燃焼を促す一方、電子の加熱は熱伝導と輻射へ漏れ得るからである。既定の Li–Petrasso の阻止能（stopping power）[5] に基づく分配は、初期化時に \(T_e,T_i,n_e\) の表にし、実行中は補間だけを行う。イオンへ渡るエネルギーの割合を \(f_i=1/(1+32/T_e[\mathrm{keV}])\) とする、より単純な Fraley の式 [4] は、DT の α 粒子に対してのみ残している。

中性子加熱のモデルは、燃料中の D/T に対する単一飛行・初回衝突の反跳（recoil）加熱で、14.049 MeV と 2.449 MeV の離散的な 2 本の線を使う。最初の衝突で平均の反跳エネルギーをその場に付与し、同じ Li–Petrasso の表で電子とイオンへ分配する。2 回目以降の飛行、カーマ（kerma。中性子相互作用が単位質量あたりに物質へ放出する運動エネルギー）、(n,2n) 反応、飛行時間（time of flight）、スペクトルの幅は明示的に省いているため、得られる分布は中性子輸送の解ではなく、燃料の自己加熱の近似である。Salpeter の 2 温度形 [2]（用語）と Chugunov–DeWitt の遮蔽オプション [3] は、低温での反応率係数を変更する。Salpeter の 2 温度化は TENRYU による拡張である。核融合のエネルギーは外部からの静止質量の源として、沈着分・逸出分・飛行中の分に分けて監査する。

反応率と燃料在庫

有効にできる反応チャネルは DT = T(d,n)⁴He、DD の D(d,p)T と D(d,n)³He、D³He = ³He(d,p)⁴He である。反応率係数には Bosch–Hale (1992) [1] のパデ近似式（Padé approximant）を使い、セルのイオン温度は入口で一度だけ eV から keV へ変換する。体積あたりの反応率は \(r=n_i n_j\langle\sigma v\rangle/(1+\delta_{ij})\) で、同種粒子どうしの DD には 1/2 が入る。近似式の下端より低温では反応率を 0 とし、上端より高温では上端の値で頭打ちにする。既定の T_floor_keV=0.2 は DT/DD の下端であり、D³He の近似式自体の下端は 0.5 keV である。

fuel_materials は、在庫をもつ、ボイド（void。定義）でない材料の名前を選ぶ。x_D、x_T、x_He3 はその初期の数分率（number fraction）で、3 つの値は非負かつ総和が 1 でなければならない。D、T、³He、⁴He、p の在庫を \(Y_s=n_s/\rho\) として保持し、反応率を評価するときだけ \(n_s=\rho Y_s\) を再構成する。これにより、純ラグランジュ運動のもとで在庫が保存され、膨張するセルで生成時の数密度を持ち越してしまう誤りを避けられる。

screening="none" は係数を 1 とする（遮蔽なし）。salpeter は電子を含む 2 温度のデバイ長（Debye length）による弱い遮蔽（weak screening）、chugunov_dewitt は剛体の電子背景（rigid electron background）を仮定した Chugunov–DeWitt 2009 の補間式（interpolation formula。文献 [3] の式 (A4)）を使う。前者の 2 温度化は TENRYU による拡張で（用語）、入力が正でない場合や有限でない場合は係数 1 へ戻り、弱結合（weak coupling）モデルからの逸脱を抑えるために、指数 \(h\)（遮蔽による反応率の増強は \(e^h\)）を \(h\le2\) に制限する。

  • \(r=n_i n_j\langle\sigma v\rangle/(1+\delta_{ij})\) — 単位体積あたりのチャネル反応率で、反応物が同種の場合は \(\delta_{ij}=1\) が DD の 1/2 の因子を与える。
  • \(Y_s=n_s/\rho\) — ラグランジュ的な比在庫である。流体的な圧縮・膨張は、\(Y_s\) 自体ではなく \(n_s=\rho Y_s\) を変化させる。
  • 温度の単位 — Bosch–Hale の近似式を評価する前に、TENRYU 内部のイオン温度を eV から keV へ一度だけ変換する。
  • 近似式の適用範囲 — 下限（DT/DD は 0.2 keV、D³He は 0.5 keV）を下回ると反応率は 0、Bosch–Hale 近似式の適用上限 [1]（DT と DD 両分岐は 100 keV、D³He は 190 keV）を超えると頭打ちにする。T_floor_keV の既定値は 0.2 である。
  • 遮蔽 — 選択した係数を、反応する対ごとの反応率係数へ掛ける。Salpeter は不正な入力に対して 1 へ戻り、弱結合モデルの指数 \(h\)（遮蔽による増幅は \(e^h\)）を \(h\le2\) に制限する。
  • Fraley の保持率 — 点源球の核が、燃料球の面密度と生成物の発生半径から局所の保持率を求める（用語）。
  • \(f_i=1/(1+32/T_e[\mathrm{keV}])\) — 任意選択の Fraley による電子・イオン分配で、設定検証により DT の α 粒子に限定される。

この計算で使う用語

燃焼のカーネルは、時間刻みの内部での進め方、在庫の持ち方、生成物のエネルギーの行き先、中性子の扱いを、この計算に固有の単位で組み立てる。ここに挙げる用語は、TENRYU の実装に固有の意味で使うので、まとめて定義する。

燃焼の段階と部分サイクル

燃焼の段階（burn stage）は、時間刻み \(\Delta t\) のあいだに燃焼のカーネルが行う更新 1 回である。外側の 1 ステップは演算子分割（operator splitting）で進み、燃焼はその列の中の 1 つの演算子に当たる（演算子分割と再クロージャの規律）。燃焼は、レーザーの直後、流体の最初の半ステップの前に置かれ、\(\Delta t\) の全体を陽的な源（explicit source）として 1 回で進める。燃焼のために \(\Delta t\) を他の演算子と交互に刻むことはない。段階のあいだ、各セルの密度と電子・イオン温度は一定に保ち、反応で生じたエネルギーは、段階の終わりに電子とイオンへの加熱源として加える。

部分サイクル（subcycling）は、段階の内部で \(\Delta t\) を \(M\) 個の等しい小区間（長さ \(\Delta t/M\)）に分け、セルごとに 5 核種のネットワークを陽的中点法（explicit midpoint method、2 次ルンゲ–クッタ）で進めることである。反応が速いセルほど細かく刻む必要があるので、\(M\) はセルごとに次の式で決める。

$$ M=\min\!\left[\max\!\left(\left\lceil\frac{\Delta t\,r_{max}}{\epsilon_{dep}}\right\rceil,1\right),M_{max}\right],\qquad r_{max}=\max_s\frac{\max(q_s^{+},q_s^{-})}{\max(n_s,\,10^{-9}n_{tot},\,1\,\mathrm{cm^{-3}})}. $$

ここで \(\epsilon_{dep}\) は eps_deplete（既定 0.1。0 より大きく 0.5 以下）、\(M_{max}\) は subcycle_max（既定 64。1 以上 4096 以下）、\(s\) は反応物の核種（D と、有効なチャネルに応じて T と ³He）、\(q_s^{+}\) と \(q_s^{-}\) は反応による核種 \(s\) の総生成率と総消費率 [cm⁻³ s⁻¹]、\(n_{tot}\) は 5 核種の数密度の和である。正味の変化率ではなく、総生成率と総消費率の大きい方を使うので、生成と消費がほぼ釣り合って入れ替わりの速い核種（DD が作った微量の T を DT がただちに消費するセルなど）も解像できる。1 部分サイクルの反応回数が反応物の在庫を使い切る場合は、回数を決定論的に縮小して正値性を保つ。必要な数が \(M_{max}\) を超えるセルがあると、上限の数で段階を進めたうえで必要数を報告し、次のステップの燃焼の時間刻みを制限する（燃料の減損と陽的な時間制御）。

在庫と比在庫

在庫（inventory）は、セルごとに持つ核種 D、T、³He、⁴He、p の 5 種の粒子数である。中性子は在庫に含めず、台帳にだけ数える。

比在庫（specific inventory） \(Y_s=n_s/\rho\) [1/g] は、質量 1 g あたりの核種 \(s\) の粒子数である。在庫は、粒子数密度 \(n_s\) [cm⁻³] ではなく、比在庫で保持する。純ラグランジュ運動ではセルの質量が変わらないので、圧縮や膨張は \(Y_s\) を変えず、\(n_s=\rho Y_s\) だけを変える。\(Y_s\) を変えるのは核反応だけである。数密度で保持すると、膨張するセルが生成時の数密度を持ち越して燃料を過剰に燃やす。比在庫は、これを防ぐための量である。反応率を評価するときだけ、現在の密度 \(\rho\) から \(n_s=\rho Y_s\) を作り直す。

初期の在庫は、セルの燃料材料（fuel_materials）の体積分率の和 \(f_{fuel}\) と、初期の数分率 \(x_D\)、\(x_T\)、\(x_{He3}\)（x_D、x_T、x_He3。既定は 0.5、0.5、0 で、総和は 1 でなければならない。既定以外の組み合わせでは 3 つとも指定する）から、\(Y_s=x_sf_{fuel}/(\bar Am_p)\)（\(s=\) D、T、³He）と置く。\(\bar A=\sum_sx_sA_s\) は燃料イオンの平均質量、\(A_s\) は陽子質量を単位とする核種 \(s\) の質量（D は 2.0141、T と ³He は 3.0160）である。⁴He と p は 0 から始まる。チェックポイントは比在庫を burn_state/specific_inventory に書き、再開はこれを使う（出力と解析）。

点源球の核と保持率

燃料球（fuel sphere）は、燃料材料の体積分率の和が vf_threshold（既定 \(10^{-3}\)）を超えるセル（燃料セル）のうち、最も内側のセルから最も外側のセルまでの連続した区間である。区間の途中にしきい値以下のセルがあっても、区間に含める。最も外側のセルの外縁の半径を \(R_b\) とする。

点源球の核（point-source sphere kernel）は、荷電生成物のエネルギーのうち燃料球の内側に沈着する割合を、閉じた式で与える。生成物は、発生したセルの中心から等方に出る点源で、一様な媒質の中を直線で進み、速度に比例する電子の抵抗を受けて \(E(s)=E_0(1-s/\lambda)^2\) に従って減速すると仮定する（\(E_0\) は生成時のエネルギー、\(s\) は飛行距離、\(\lambda\) は飛程）。発生点の半径を \(r\)、\(u=r/R_b\)、飛行方向と外向きの動径方向のなす角の余弦を \(\mu\) とすると、発生点から燃料球の表面までの距離は、\(R_b\) を単位として \(L(\mu)=-u\mu+\sqrt{1-u^2+u^2\mu^2}\) である。燃料球の半径を飛程で割った値を \(\tau=R_b\bar\rho/(\rho\lambda)\) と置くと、沈着する割合 \(f(u,\tau)\) は次のようになる。

$$ f(u,\tau)=\frac12\int_{-1}^{1}\Bigl\{1-\bigl[1-\min\bigl(\tau L(\mu),1\bigr)\bigr]^2\Bigr\}\,d\mu . $$

ここで \(\bar\rho\) は、発生したセルの中心から \(R_b\) までの動径方向の密度の台形則による平均 [g/cm³]、\(\rho\lambda\) は生成物の飛程を面密度で表した値 [g/cm²] である（\(\rho\lambda/\bar\rho\) が飛程の長さに当たる）。

保持率（retained fraction）は、この \(f(u,\tau)\) である。保持された分 \(f\) は発生したセルへ沈着し（電子とイオンへの分配は partition による）、残りの \(1-f\) は燃料球の外へ出るエネルギーとして荷電粒子の逸出台帳へ送る。中心（\(u=0\)）では \(f=1-[1-\min(\tau,1)]^2\) で、\(\tau\ge1\) なら 1 になる。燃料球の表面（\(u=1\)）では、\(\tau\) を大きくしても \(f\) は 1/2 に近づくだけである（外向きに出る半分が外へ逃げる）。一様な球の内側に一様に分布する点源について平均すると、古典的な式 \(f(\tau)=\tfrac32\tau-\tfrac45\tau^2\)（\(\tau\le\tfrac12\)）、\(f(\tau)=1-\tfrac1{4\tau}+\tfrac1{160\tau^3}\)（\(\tau\ge\tfrac12\)）になる。

飛程（range）は、3.54 MeV の DT の α 粒子については、Fraley の当てはめ式 [4]

$$ \rho\lambda_\alpha=\frac{1.5\times10^{-2}\,T_e^{5/4}}{1+8.2\times10^{-3}\,T_e^{5/4}}\cdot\frac{1+0.17\ln T_e}{1+0.17\ln\bigl(T_e\sqrt{\rho_0/\rho}\bigr)}\ \ [\mathrm{g/cm^2}],\qquad \rho_0=0.213\ \mathrm{g/cm^3} $$

で与える（\(T_e\) は keV、\(\rho\) は g/cm³ で、\(T_e\) は 0.1 keV 以上に、2 つの対数の因子は 0.15 以上に制限する）。他の生成物の飛程は、\(\lambda_s=\lambda_\alpha\sqrt{A_sE_s/(A_\alpha E_\alpha)}\,(Z_\alpha/Z_s)^2\) で α 粒子から換算する（\(A\) は質量、\(E\) は生成エネルギー、\(Z\) は電荷）。セルの組成（燃料と灰）に応じて、電子の項とイオンの項を補正し、等モルの DT では補正が 1 になる。直線飛行、一様な媒質、動径方向の平均密度という近似を使うので、斜めに進む弦の密度の層構造は反映しない。

この核は、飛行を追跡せずに、荷電生成物のうち燃料の自己加熱に使われる分と逃げる分を、1D の球対称の計算で安価に見積もるために使う。既定の scheme="fraley"（1D 専用）が使い、保持率が電子とイオンへ沈着するエネルギーと逃げるエネルギーを決めるので、自己加熱の強さと点火余裕に効く。\(\tau\) が小さい（飛程が燃料球より長い）ほど、逃げる割合が大きい。たとえば \(u=0\)、\(\tau=0.5\) なら \(f=0.75\)、\(u=0.5\)、\(\tau=1\) なら \(f=0.94\) である。

飛行中と燃焼の台帳

飛行中（in flight）のエネルギー \(E_{inflight}\) は、すでに生成されたが、まだセルへ沈着も系外へ逸出もしていない荷電生成物が運ぶエネルギーである。多群拡散では群ごとの比スペクトル \(Y_g=N_g/\rho\) [1/g]（\(N_g\) は群 \(g\) の粒子数密度。比在庫と同じく質量あたりで保持する）が、モンテカルロではステップをまたいで保持する粒子が、これを次のステップへ持ち越す。fraley と local では、生成物は生成したステップのうちに沈着か逸出のどちらかに決まるので、\(E_{inflight}=0\) である。

燃焼の台帳（burn ledger）は、燃焼が解放したエネルギーの行き先を記帳する量で、全体のエネルギー台帳の一部である。荷電生成物については、毎ステップ次の恒等式を丸め誤差の範囲で課す（解放 = 沈着 + 逸出 + 飛行中の変化）。

$$ E_{rel}=E_{dep}+E_{esc}+\Delta E_{inflight}. $$

ここで \(E_{rel}\) は荷電生成物が解放したエネルギー、\(E_{dep}\) は電子とイオンへ沈着したエネルギー、\(E_{esc}\) は系外へ出たエネルギー（fraley では燃料球の外へ出る分、diffusion と mc では外面から出る分）、\(\Delta E_{inflight}\) はそのステップでの飛行中のエネルギーの変化である。中性子については、neutron_heating を切ると解放した全エネルギーが逸出に入り、有効にすると「放出 = 沈着 + 減速後 + 逸出」を課す（初回衝突と単一飛行）。全体のエネルギー台帳には、流体へ沈着した分だけを外部からの源として加える。逸出分と中性子は流体に入らないので、損失としては数えない。履歴の burn/released、burn/dep_e、burn/dep_i、burn/esc_charged、burn/esc_neutron、累積の burn/E_released_cum など、および burn/E_inflight（diffusion と mc だけ）が、この台帳である（履歴のチャネル）。

初回衝突と単一飛行

初回衝突（first collision）は、中性子が燃料の D または T と起こす最初の弾性散乱である。

単一飛行（single flight）は、各中性子を放出点から球の外面まで 1 本の直線（弦）に沿って 1 回だけ飛ばし、最初の衝突のあとで散乱した中性子を追跡しないという取り扱いである。

中性子は 2 本の線、DT の 14.049 MeV と DD の 2.449 MeV で放出する。放出するセルの中心の半径から、方向余弦 \(\mu\) を偶数次のガウス–ルジャンドル求積で刻んで等方に放出し（\(\mu\) の点の数は neutron_heating_n_mu。既定 16、2 以上 64 以下の偶数）、各方向の弦を球殻の境界ごとにたどる。殻の区間 \(\Delta s\) で衝突する割合は \(T_{rem}(1-e^{-\Sigma\Delta s})\) である。\(\Sigma=n_D\sigma_D+n_T\sigma_T\) は燃料の D と T の弾性散乱の巨視断面積（数密度 \(n_D\)、\(n_T\) は在庫 \(\rho Y_s\) から作る）、\(T_{rem}\) はそこまでの透過率である。燃料以外の材料、⁴He、p は透明として扱う。衝突した中性子のエネルギーのうち、反跳した核が受け取る平均の割合 \(f\) を、その殻のセルへ沈着させ、電子とイオンへの分配には Li–Petrasso の表の反跳用の項目を使う。残りの \(1-f\) は、散乱した中性子が持ち去る分として追跡せず、台帳に degraded（減速後）として記帳する。衝突しなかった分は escaped（逸出）として記帳する。

Salpeter の 2 温度形

Salpeter の 2 温度形（two-temperature Salpeter form）は、screening="salpeter" のときに反応率係数へ掛ける増強係数である。反応する核種の対 \((i,j)\) ごとに \(\langle\sigma v\rangle\to F\langle\sigma v\rangle\)、\(F=\exp h\) と置く。遮蔽の長さ \(\lambda\) は、イオンと電子が別々の温度をもつデバイ長で、

$$ \lambda^{-2}=4\pi e^2\left[\frac{\sum_sn_sZ_s^2}{k_BT_i}+\frac{n_e}{k_BT_e}\right],\qquad h=\frac{Z_iZ_je^2}{\lambda\,k_BT_i} $$

である。ここで \(e\) は電気素量、\(n_s\) は在庫から作る 5 核種の数密度、\(Z_s\) はその電荷（D、T、p は 1、³He と ⁴He は 2）、\(n_e=\bar Z\rho/(Am_p)\) は電子数密度、\(Z_i\) と \(Z_j\) は反応する 2 核種の電荷である。Salpeter [2] の式は、イオンと電子が共通の温度をもつ平衡を仮定する。\(T_i\ne T_e\) の場合へ拡張したのは TENRYU である。弱遮蔽の近似は \(h\ll1\) でだけ成り立つので、\(h\le2\)（増強は \(e^2\approx7.4\) 倍まで）に制限し、制限が働くと初回だけ警告する。入力（\(T_i\)、\(T_e\)、\(n_e\)）が正でないか有限でないときは \(F=1\) とする。chugunov_dewitt は、剛体の電子背景を仮定した Chugunov–DeWitt の補間式 [3] で、ここで定義する 2 温度形ではない。

燃料の減損と陽的な時間制御

燃焼の各段階では温度と密度を一定に保ち、核種のネットワークを陽的中点法（explicit midpoint method、2 次ルンゲ–クッタ）でセルごとに部分サイクルに分けて進める。必要な部分サイクルの数は、有効な各反応物について総生成率と総消費率の大きい方から求め、1 部分サイクルあたりの相対的な在庫変化が eps_deplete 以下になるようにする。これにより、DD が作った微量の T を DT がただちに消費するような、正味の変化が小さい生成消費の回転も解像できる。正値性（positivity）は、反応回数を決定論的に縮小することで守る。

必要な部分サイクルの数が subcycle_max を超える場合は、上限の数のまま現在のステップを進めたうえで必要数を報告し、次のステップの燃焼の時間刻みへ \(0.9\,dt\,M_{max}/M_{req}\) を反映させる（\(M_{req}\) は要求された部分サイクルの数、\(M_{max}\) は subcycle_max で与える上限）。さらに沈着パワー \(P_{dep}\) に対して \(\Delta t\le f_E e_{cell}/P_{dep}\)、\(f_E=\)explicit_source_limit を課す。ここで \(e_{cell}=\rho_cV_c(e_e+e_i)\) はセルの全内部エネルギーで、ホット電子（hot electron）の物理カーネルの同名キーと同じ形の制限（あちらは電子エネルギー、こちらは電子+イオン）である。これは、段階の内部で温度を更新し直すことなく自己加熱を小さく保つための、源に対する制限である。

1 回の燃焼段階の手順

  1. 燃焼の段階のあいだ、各セルの密度と電子・イオン温度を一定に保つ。
  2. 有効なチャネルの反応率を計算し、2 次ルンゲ–クッタ（RK2）に必要な部分サイクルの数を各反応物の総生成率と総消費率から決めて、1 部分サイクルあたりの相対的な在庫変化を eps_deplete 以下に抑える。正味の変化ではなく総量を使うことで、微量の T が DD で生成され DT で消費される回転を解像できる。
  3. 5 核種のネットワークを陽的中点法で進める。提案された反応回数が反応物を使い切ってしまう場合は、在庫を再構成する前に回数を決定論的に縮小し、正値性と化学量論（stoichiometry）の収支を保つ。
  4. 必要な部分サイクルの数が subcycle_max に張り付いた場合は報告し、\(0.9\,dt\,M_{max}/M_{req}\) を次の燃焼の時間刻みの制限へ反映させる。これとは独立に、沈着する源のパワーに対して \(\Delta t\le f_E e_{cell}/P_{dep}\) を課す。
  5. 荷電生成物を、選択した方式（1D は fraley、diffusion、mc、2D RZ は local、diffusion）へ渡し、中性子は任意選択の初回衝突加熱の経路（1D 専用）へ渡す。
  6. 沈着したエネルギーを電子とイオンの源へ分配し、燃焼の台帳（沈着・逸出・飛行中）を更新して、まとめた燃焼の時間刻み制限をドライバへ渡す。

生成物の輸送と電子・イオン分配

既定の scheme="fraley" は、Fraley による α 粒子の飛程の近似式と、点源球の核を使う [4]（点源球の核と保持率）。燃料球の面密度と発生半径から局所の保持率を求め、保持された分を発生したセルへ、残りを荷電粒子の逸出台帳へ送る。scheme="diffusion" は Corman 1975 の多群方程式 [6] により、6 種類の生成物 — チャネル別の荷電生成物である DT の α、DD の陽子・三重陽子（triton）・ヘリオン（helion。³He の原子核）、D³He の陽子と α — について飛行中の比スペクトルを追跡し、群間の減速で失うエネルギーを沈着させる。scheme="mc" は、Yuan らの Monte Carlo 追跡 [8] と同じ型の、直線的に進む連続減速近似の粒子をステップをまたいで保持し、生成物・セル・ステップあたり mc_particles_per_cell 個を標本化する。モンテカルロの集計は統計的だが、各粒子のカウンタ型乱数（counter-based random number generator）の Philox 列（Philox4x32-10）は大域 ID によって独立に決まる。local は 2D RZ 専用で（1D では拒否される）、生成物のエネルギーを輸送せず、発生セルへ全量沈着する（電子・イオンへの分配は他の方式と共通）。

局所沈着に対する既定の分配 partition="li_petrasso" は、初期化時に Li–Petrasso の阻止能を \(T_e,T_i,n_e\) の表にし、実行中は補間だけを行う。もう一方の fraley は \(f_i=1/(1+32/T_e[\mathrm{keV}])\) で DT の α 粒子に限られ、scheme が fraley か local のとき、DD や D³He との併用は拒否される。Fraley の式は DT の α 粒子に対する近似で、反跳した D と T のエネルギーを電子とイオンへ分配できないので、中性子加熱（neutron_heating）との併用も拒否される。多群拡散とモンテカルロは、それぞれ自身の阻止の計算に分配を含んでいるため、このキーを使わない。

中性子加熱

neutron_heating=True（1D 専用）にすると、DT の 14.049 MeV と DD の 2.449 MeV の中性子を等方に放出し、neutron_heating_n_mu 点のガウス–ルジャンドル求積（Gauss–Legendre quadrature）で球殻を横切る弦（chord）をたどる。減衰は燃料中の D/T による弾性散乱断面積（elastic-scattering cross section）だけから求め、最初の衝突で平均の反跳エネルギーをそのセルへ局所的に沈着させる（初回衝突と単一飛行）。反跳した D/T の電子・イオンへの分配には、Li–Petrasso の表を再利用する。散乱後に残る中性子のエネルギーは degraded（減速後）、外面から出る分は escaped（逸出）として記帳する。

このモデルは単一飛行である。減速した中性子の多重飛行、シェル材料のカーマ、(n,2n) 反応、飛行時間による遅れ、反跳スペクトルの幅は含まない。したがって中性子加熱の空間分布を解釈する際は、燃料の自己加熱に対する初回衝突の近似として扱うこと。

検証

  • 単体試験 test_burn_reactivity は、Bosch–Hale の Table VIII にある 8 温度 × 4 反応の基準値を相対 \(1.5\times10^{-3}\) 以内で固定し、keV と eV の取り違えを検出する。単体試験 test_burn_network は、閉じた形の DT/DD 解、生成された T を含む連鎖反応、総量に基づく部分サイクル、化学量論的な反応回数を検査する。
  • 単体試験 test_burn_deposition の節 G-K0、G-K1、G-K2（試験のタグの凡例）は、それぞれ Fraley の飛程の基準値、点源球の核の恒等式、球平均の閉じた形の解を検査し、節 G-P1、G-P2 は、Li–Petrasso の公刊済み阻止能の参照値（文献 [5] の Table I）と、意図的に異なる値をとる Fraley の分配を検査する。6 回の実行からなるマイクロスフィア（microsphere）の検査 burn_rung2_microsphere は、燃料対の上限、反応率のスケール、初期の α 粒子の再捕獲による自己加熱を組み合わせる。
  • 機能を無効にした実行と基準の実行との A/B 対比較では、場が 53/53、履歴が 164/164 でビット単位に一致し、GXII（激光 XII 号、GEKKO XII）の基準解でも相対差 0 を 6 回確認した。燃焼段階の台帳の検査と、多群拡散・モンテカルロの輸送の検査は、「解放 = 沈着 + 逸出 + 飛行中の変化」という台帳の恒等式を、丸め誤差の範囲で課す。
  • 単体試験 test_burn_neutron_heating は、中性子加熱に固定した定数表（断面積と反跳の割合）、光学的に薄い極限、球に対する解析的な減衰、「放出 = 沈着 + 減速後 + 逸出」を判定する。モンテカルロについては、同じ乱数の種（seed）での変動係数（coefficient of variation）0.1% 以下、異なる乱数の種での変動係数 5% 以下と、乱数列の独立性を別途検査する。
