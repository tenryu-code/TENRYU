RZ 運動量スキーム

2D RZ の運動量式には、体積重み付き（volume_weighted）と面積重み付き（area_weighted_symmetric）の 2 つがある。この頁は、両者の違い、既定が面積重み付きである理由、エネルギー整合な仕事（aw_compatible_force_work）、BBSW のコーナー質量で測る運動エネルギー、ほかの設定との組み合わせの制約を述べる。この計算に固有の用語は用語の節で説明する。

この計算で使う用語

2D RZ の運動量式は、コーナーベクトル、コーナー質量、コーナー力から節点の加速度を求める。記号 \(c\)、\(k\)、\(n\)（セル、コーナーの番号、節点）と、これらの量の定義は、空間離散化の頁の用語の節にある。この節は、運動量式に固有の用語を定義する。

面積重み付き・体積重み付きの運動量式と BBSW のコーナー質量

体積重み付き（volume-weighted）運動量式は、体積勾配のコーナーベクトル \(\mathbf S_{c,k}\) から作ったコーナー力を節点で足し合わせ、コーナー質量から作る真の RZ 節点質量 \(m_n\) で割って、節点の加速度を求める。力と体積変化率が同じベクトルを共有するので、エネルギー整合が成り立つ。

面積重み付き（area-weighted）運動量式は、R–Z 面の平面で作ったコーナー力 \(\mathbf F^A_{c,k}=(P_c+Q_c)\,\mathbf S^A_{c,k}\) を節点で足し合わせ、平面の節点質量 \(M^A_n\)（既定では、下に定義する BBSW のコーナー質量から作る）で割って、節点の加速度を求める。この式を採る理由はRZ 運動量スキームの節に述べた。2D RZ のデッキで省略したときの既定である（rz_momentum_scheme="area_weighted_symmetric"）。

BBSW のコーナー質量（BBSW corner mass）\(m^B_{c,k}\) は、面積重み付きでエネルギー整合な運動量式が運動エネルギーを測る質量で、Barlow–Burton–Shashkov–Wendroff [1] の定義に従う。

$$ m^B_{c,k}=M_c\,\frac{r_kA^k_c}{\sum_jr_jA^j_c}, \qquad A^k_c=\frac{T_{k-1}+T_k}{3}+\frac{A_c}{12}. $$

ここで \(M_c\) はセル質量、\(r_k\) はコーナー \(k\) の節点の半径、\(T_k\) は辺 \(k\)（コーナー \(k\) と \(k+1\) を結ぶ辺）とセルの頂点平均を頂点にもつ三角形の面積、\(A_c=\sum_kT_k\) はセルの平面面積である（\(A^k_c\) の式は四辺形のもの）。\(\sum_km^B_{c,k}=M_c\) で、軸上の節点のコーナーでは \(m^B_{c,k}=0\) である。節点の質量は \(M^B_n=\sum_{(c,k)\to n}m^B_{c,k}\)、平面の節点質量は \(M^A_n=M^B_n/(2\pi r_n)\)、運動エネルギーは \(K^B=\tfrac12\sum_nM^B_n|\mathbf u_n|^2\) で測る。この質量と、内部エネルギーの仕事の重み \(2\pi r\) により、各段で \(\Delta K^B+\sum_c\Delta U_c=W_{ext}\) が満たされる。aw_kinetic_measure="bbsw_subzonal" が省略時の既定で、"planar_v1" は以前の測度であり、この恒等式を閉じない。

RZ 運動量スキーム

2D RZ の運動量式は 2 つある（定義は用語の節）。volume_weighted は、回転体体積の厳密な勾配である体積勾配のコーナーベクトルと、コーナー質量から作る真の RZ 節点質量を使う。area_weighted_symmetric は、R–Z 面の平面で作った平面コーナーベクトルと、平面の節点質量を使う。rz_momentum_scheme を省略したときの既定は、2D RZ のデッキで area_weighted_symmetric、構造体の既定（C++ のコードで組む Config の値）で volume_weighted である。

球対称な状態を等角（equal-angle）の極座標メッシュで解くとき、面積重みの力は全節点で動径方向を向く。体積重みの力は、極軸（polar axis。球座標メッシュの \(\theta=0\) と \(\theta=\pi\) の線）に隣接する節点で角度方向の成分をもち、膨張する爆風（blast wave）でそのまわりのセルを絡ませる。面積重みの式は、この絡みを避けるために採る。

aw_compatible_force_work=True（2D RZ のデッキで省略したときの既定）では、運動量に平面のコーナー力を使い、内部エネルギーの仕事には、同じ力に \(2\pi r\) を掛けた回転体の力を使う。運動エネルギーは、BBSW のコーナー質量から作る節点質量で測る（aw_kinetic_measure="bbsw_subzonal"、省略時の既定）。この組は、各段で \(\Delta K^B+\sum_c\Delta U_c=W_{ext}\) を満たすように構成する。ここで \(\Delta K^B\) は BBSW の節点質量で測った運動エネルギーの変化、\(\sum_c\Delta U_c\) はセルの内部エネルギーの変化の和、\(W_{ext}\) は外部の仕事である。aw_kinetic_measure="planar_v1" は以前の測度で、この恒等式を閉じない。

aw_compatible_force_work=True は、av_model が csw_edge、csw_edge_csw98、mimetic_tensor_v1、mimetic_tensor_rz_v2 のいずれかであること、subzonal_pressure_enabled=True であることを要求する。False のときは、av_model="scalar_vnr_legacy" で、サブゾーン圧力を無効にする必要がある。このとき内部エネルギーは従来どおり真の RZ 体積変化による \(p\,dV\) で更新するので、全エネルギーは構成上の恒等式では保存されない（エネルギー整合でない）。診断量、時間刻みの見積り、リマップは真の RZ 節点質量を使う。time_integration の既定の midpoint_v1 はエネルギー整合な仕事を要するので、面積重み付きの運動量式で aw_compatible_force_work=False とするデッキは、time_integration="pc_v0" も明示する。midpoint_v1 との組は入力検証が拒否する。

area_weighted_symmetric は 2D RZ だけで使え、構造化された単一ブロックメッシュと、マルチブロックの CSR メッシュを対象とする。aw_compatible_force_work=False では、マルチブロックメッシュは全セルが四辺形のものに限る。三角形扇（triangular fan、tri-fan）を極冠（polar cap）にもつマルチブロックメッシュ（multiblock_half_butterfly_trifan_cap_5block）と、Numerics.hydro.plasma_viscosity を有効にした計算は、入力検証が拒否する。aw_compatible_force_work=True では、Mesh.polar_center_treatment が tri_fan または button の中心も拒否する。これらを使うデッキは、rz_momentum_scheme="volume_weighted" と aw_compatible_force_work=False を明示する。Studio は、logical_mesh_2d="polar_in_box"（中心が tri_fan）のデッキにだけ、この 2 つに加えて av_model="scalar_vnr_legacy" と subzonal_pressure_enabled=False を書き出す。ほかの 2D RZ のデッキには、流体のこれらのキーを書かず、省略したときの既定で走らせる。

namelist による制御

以下は Numerics.hydro の主要キーの抜粋である。既定値は、デッキで省略したときの値である。2D RZ のデッキで省略したときと、構造体の既定（C++ のコードで組む Config の値）とで値の違うキーには、両方を書く。Studio は、logical_mesh_2d="polar_in_box" のメッシュを除いて、2D RZ の流体にこの表のキーを書かないので、Studio のデッキは 2D RZ で省略したときの既定で走る。全項目と検証規則は namelist リファレンスを参照のこと。

aw_compatible_force_work2D RZ のデッキで省略したとき True、構造体の既定は False面積重み付きの運動量式で、内部エネルギーの仕事を運動量と同じ力から作る（エネルギー整合）。True は、av_model の辺人工粘性またはテンソル粘性と、subzonal_pressure_enabled=True を要する。
