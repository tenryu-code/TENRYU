輻射輸送

TENRYU は、物質（matter。電子の内部エネルギー）と連成した多群（multigroup）の輻射輸送（radiation transport）を、Radiation.mode で選ぶ 2 つの実運用向けの決定論的（deterministic）なソルバで解く。多群の流束制限拡散（flux-limited diffusion、FLD。"multigroup_diffusion"）と、離散座標法（discrete ordinates method）による \(S_N\) 輸送（"sn_transport"）である。どちらも、1D の 3 つの座標幾何（Mesh.geometry_1d の球・円筒・平面）と、2D の軸対称（axisymmetric）RZ の幾何で動作する。群の構造と材料クロージャ（material closure。保存量から圧力、温度、不透明度などを求める関係で、EOS・不透明度・電離の頁で説明する）を共有するが、角度の扱い方と、物質との連成を解く方法が異なる。この頁では両モデルを説明して比較し、それぞれの詳細頁へ案内する。

多群 FLD

Fleck 線形化（Fleck linearization）による物質との連成を用いる流束制限拡散。

SN 輸送

掃引（sweep）と、反復で解く物質との連成を用いる離散座標法の輸送。

2 つのモデル

多群 FLD。 多群の流束制限拡散は、光子のエネルギーを光子エネルギー群（photon-energy group。光子のエネルギー範囲を区切った各区間）に分け、Fleck 線形化によって物質との硬い（stiff。時定数が時間刻みよりはるかに短い）放出・吸収を陰的（implicit）に連成する。Fleck 係数 \(f\) は、吸収のうち物質のエネルギーを実際に変える割合で、残りの \(1-f\) は、吸収した輻射が同じステップ内で再放出される、散乱に似た過程（実効散乱、effective scattering）として扱う（群構造と Fleck 線形化）。1D では群を一括処理する三重対角（tridiagonal）の系を解く。2D RZ では、節点局所の演算子（node-local operator。各セルの辺を中点で 2 つの半辺に分け、節点ごとに、その節点側の半辺の値を消去して得る、セル中心の値どうしを結ぶ対称な演算子）から群ごとの保存型有限体積（conservative finite-volume）の系を CSR（compressed sparse row）形式の疎行列として構成し、共役勾配法（conjugate gradient method、CG）で解く。前処理（preconditioner）は既定では集約多重格子（aggregation multigrid）で、集約の条件を満たさない格子では対角前処理である。光学的に厚い（optically thick）領域では拡散極限（diffusion limit）を回復し、Levermore–Pomraning の流束制限関数（flux limiter）が薄い領域での輸送を抑える。

\(S_N\) 輸送。 離散座標法の輸送は、光子エネルギー群ごとに有限個の方向（離散座標、ordinate）を追跡し、方向別の輻射強度（specific intensity）からセルのエネルギーと面の流束を構成する。\(S_N\) の \(N\) は角度求積の次数を表す整数で、Radiation.sn_transport.n_angles（許容値は 2、4、8、16、32。既定は 16）で与える。1D の円筒だけは、このキーに \(n=2L^2\)（レベル数 \(L\) は 2 以上 32 以下の整数。8、18、32、…）を与える。波面（wavefront。上流の処理が済めば同時に処理できるセルの集まり）に沿う掃引に源反復（source iteration）を組み合わせる。物質との連成は、2D RZ と 1D の線形特性法（linear characteristic scheme）ではピカール反復（Picard iteration）で、1D の既定の線形不連続法（linear discontinuous scheme）では節点の電子温度についてのニュートン法（Newton's method）で解く。角度の情報を保持するため、拡散のクロージャでは表せない自由飛行（free streaming）、影（shadowing）、異方性（anisotropy）を扱える。

比較と使い分け

観点多群 FLD\(S_N\) 輸送
角度の扱いスカラーのエネルギーと、制限付きの拡散流束（角度の分布は、流束制限関数というクロージャで与える）。離散的な方向 \(\{\boldsymbol\mu_m,w_m\}\)（\(\boldsymbol\mu_m\) は方向余弦、\(w_m\) は求積の重み）。1D の球・平面はガウス–ルジャンドル求積（Gauss–Legendre quadrature）で、実運用の既定は \(S_{16}\)。1D の円筒と 2D RZ は直積型の求積（product quadrature）である。2D RZ の方向は、軸方向の方向余弦 \(\mu_z\) についての \(N\) 点のガウス–ルジャンドル求積と、方位角の半周を \(N/2\) 等分した中点との直積で、方向数は \(N^2/2\) になる。
有効な領域光学的に厚く、ほぼ等方な輻射場。光学的に薄い（optically thin）自由飛行、方向性のある照射、影、レイ効果（ray effect）まで扱える。
物質との連成Fleck 線形化と、外側反復（outer iteration。物質の温度と輻射場の連成を収束させる反復）およびセル局所のニュートン法による物質の更新。Fleck の実効散乱を使わない（\(f=1\)）。吸収と放出には、群ごとのプランク平均（Planck mean）の吸収不透明度（opacity）\(\sigma^{PA}\) と放出不透明度 \(\sigma^{PE}\) を、そのまま使う。2D RZ と 1D の線形特性法は、源反復と外側のピカール反復で連成を解き、各セルの物質温度は能動集合によるニュートン法（active-set Newton method。セルごとに、物質のエネルギー収支の式をニュートン法で解く。群の輻射エネルギーは 0 以上とし、この制約に掛かった群（能動集合）は 0 に固定して扱う）で求める。1D の既定の線形不連続法は、節点の電子温度についてのニュートン法で連成を解く。
計算量とソルバ群ごとに 1 回の拡散求解：1D は一括処理の三重対角、2D RZ は節点局所の演算子の疎行列を、集約多重格子（既定。集約の条件を満たさない格子では対角前処理）で前処理した共役勾配法で解く。計算量はおよそ、セル数 × 群数 × 方向数 × 反復数。角度と面の作業領域も必要である。
幾何1D（球・円筒・平面）& 2D RZ。1D（球・平面はガウス–ルジャンドル、円筒は \(n=2L^2\) 本の直積型の求積）& 2D RZ。
迷ったときは輻射爆縮（radiation-driven implosion）における実運用の既定である（GXII（激光 XII 号、GEKKO XII）の基準回帰試験、golden-reference regression test）。S8、S16、S32 と次数を上げた一連の計算で、着目量の収束を確認する。

透明な空隙（transparent gap）、自由飛行する輻射の前面（front）、方向性の強い照射、影、レイ効果のように、角度分布そのものが解の一部になる場合は \(S_N\) を選ぶ。FLD は角度をスカラーのエネルギーと制限付きの拡散流束に閉じるため、光学的に厚くほぼ等方な領域では一般に安価である。方向数を減らせば計算は安くなるが、角度の打ち切り誤差（angular truncation error）とレイ効果が大きくなる。

両モデルが共有するもの

  • 共有する光子エネルギー群の境界、プランク分率（Planck fraction）\(b_g(T)\)（温度 \(T\) の黒体輻射のエネルギーのうち、群 \(g\) に入る割合）、電子の状態方程式（equation of state、EOS）から評価する基本量（内部エネルギーや熱容量など）。
  • 反射（reflecting）、真空（vacuum）、Marshak（Marshak boundary condition。外部の輻射場から入射する流束を与える）の 3 種類の境界条件。面の種別は、モードごとのブロックの下に置く。
  • ボイド（void）セル（Material.is_void が真の材料で満たしたセル）は、物質との交換から除外する。
  • エネルギー台帳（energy ledger。輻射と物質のあいだ、および境界を出入りするエネルギーを項目別に記録した帳簿）の収支が、機械精度（machine precision）で閉じる。
  • 内部の単位系 cgs + eV。
