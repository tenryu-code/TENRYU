輻射輸送

TENRYU は、電子物質と連成した多群の輻射輸送を、Radiation.mode で選ぶ 2 つの実運用向け決定論的ソルバで解く。多群の流束制限拡散（"multigroup_diffusion"）と、離散座標法による \(S_N\) 輸送（"sn_transport"）である。どちらも 1D — Mesh.geometry_1d の 3 つの測度（球・円筒・平面）すべて — と 2D 軸対称 RZ の幾何で動作し、群の構造と物質側の閉包を共有するが、角度の扱い方と、物質との結合の閉じ方が異なる。このページでは両モデルを説明・比較し、それぞれの詳細ページへ案内する。

多群 FLD

Fleck 線形化による物質との連成を用いる流束制限拡散。

SN 輸送

掃引と反復的な物質閉包を用いる離散座標法の輸送。

2 つのモデル

多群 FLD。 多群の流束制限拡散は、光子のエネルギーを群に分け、Fleck 線形化によって電子物質との「硬い」（時定数が時間刻みよりはるかに短い）放出・吸収を陰的に連成する。1D では一括処理する三重対角の系を、2D RZ では共役勾配法系のソルバを用いる 5 点 CSR の保存型有限体積の系を構成する。光学的に厚い領域では拡散極限を回復し、Levermore–Pomraning の流束制限関数が薄い領域での輸送を抑える。

\(S_N\) 輸送。 離散座標法の輸送は、光子エネルギー群ごとに有限個の方向を追跡し、方向別の放射強度からセルのエネルギーと面の流束を構成する。波面に沿う掃引に、源反復とピカール法による物質との連成を組み合わせる。角度の情報を保持するため、拡散のクロージャでは表せない自由飛行、影、異方性を扱える。

透明な空隙、自由飛行する波面、方向性の強い照射、影、レイ効果のように、角度分布そのものが解の一部になる場合は \(S_N\) を選ぶ。FLD は角度をスカラーのエネルギーと制限付きの拡散流束に閉じるため、光学的に厚くほぼ等方な領域では一般に安価である。方向数を減らせば計算は安くなるが、角度の打ち切り誤差とレイ効果が大きくなる。

両モデルが共有するもの

  • 共有する光子エネルギーの群境界、プランク分率 \(b_g(T)\)、電子 EOS の基本量。
  • 同じ境界条件の族（反射、真空、Marshak）。面の種別は、モードごとのブロックの下に置く。
  • VOID のセルを物質との交換から除外する、ボイドセルの契約。
  • 機械精度で閉じる、境界と物質のエネルギーの台帳。
  • 内部の単位系 cgs + eV。
