# TENRYU β

## TENRYU β の概要

TENRYU β は、1D 球対称 Lagrangian 放射流体計算と、
その設定・実行を支援する GUI「TENRYU Studio」の評価版です。

本リポジトリには 2D_RZ コードも含まれますが、
2D_RZ は今回の β サポート対象外です。
評価とフィードバックは 1D 計算および GUI を中心にお願いします。

## 構成

TENRYU は次の2つの要素で構成されます。

- 計算コア: Linux + CUDA サーバ上でビルドし、計算を実行します。
- GUI: macOS アプリとして動作し、SSH 経由で計算サーバへ接続します。

GUI は入力デッキの作成、サーバへの転送、ジョブの実行、
および結果確認の入口を提供します。
計算自体は登録した Linux サーバ上の TENRYU が実行します。

## クイックスタート

1. [BUILD.md](BUILD.md) に従って計算サーバ上で TENRYU をビルドします。
2. TENRYU Studio を起動し、SSH 接続先となるサーバを登録します。
3. サーバ設定にビルド済み `tenryu` の絶対パスを指定します。
4. GUI で 1D プリセットを選び、必要な条件を設定します。
5. 入力内容を確認して実行します。

初回評価では、標準プリセットから始めることを推奨します。
問題を報告する際は、同じ条件を再現できる入力デッキも保存してください。

## macOS Gatekeeper に関する注意

TENRYU Studio の `.app` は未署名です。
初回起動時に macOS によって起動が拒否された場合は、
Finder でアプリを右クリックし、「開く」を選択してください。

必要に応じて、ターミナルから次のコマンドで隔離属性を解除できます。

```bash
xattr -cr "TENRYU Studio.app"
```

入手元と配置先を確認したうえで実行してください。

## 既知の制限

- β サポート範囲は 1D 球対称 Lagrangian 放射流体計算と GUI です。
- 2D_RZ コードは同梱されていますが、今回の β サポート対象外です。
- `polar_in_box` は初期格子プレビューのみ（実行は今後の版）です。
- GUI および計算コアの仕様は、β 期間中に変更される可能性があります。
- 未署名の macOS アプリであるため、初回起動時に手動操作が必要です。

## データテーブルについて

材料データテーブル（SESAME、Propaceos 由来の TMAT テーブル）はライセンス上の理由で
本リポジトリに含まれません。ideal-gas EOS・constant opacity を使う検証デッキ
（noh / sod / su_olson など）はそのまま実行できます。SESAME/TMAT を要するデッキ
（GXII プリセット、hot-electron 系）は、各自が正規に入手したテーブルを
`SESAME/`・`TMAT-H5/` に配置し、必要に応じて `tools/tmat/` の変換スクリプトで
生成してください。
