概要

TENRYU は、エネルギー整合なラグランジュ流体を中核とし、複数の物理演算子をストラング分割で時間発展させる構成である。この節では、コードの対象範囲と設計原則、モジュール構成、全カーネルに共通する数値基盤、そしてすべての変更を判定する検証の哲学を説明する。

アーキテクチャとモジュール地図

数値基盤

共通の方程式、変数配置、単位系、演算子順序、時間刻み制御を説明する。

時間刻み制御と CFL

大域 Δt の決定則と、カーネル別の CFL・安定条件の式を一覧する。

解析解による検査、基準解との回帰、再現性の試験、ベンチマークによる証拠の積み上げを示す。
