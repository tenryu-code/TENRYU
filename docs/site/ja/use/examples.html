例題とプリセット reference

TENRYU Studio の 1 次元プリセットは、圧力で駆動する衝撃波・輻射熱波・平面の箔のレーザー照射・球殻の直接照射爆縮・輻射温度による間接照射という基本の構成と、S_N 輸送・非局所電子熱伝導 (SNB)・CBET と高速電子・核燃焼・物性表と多群輻射・低温平衡の構成則というオプションのカーネルを使う構成を収める。CBET のもの以外は 2026-10-01 に RTX 4090 で終了時刻まで計算し、2 倍細かいメッシュの計算と比べて確かめた。典型実験を扱うコミッショニング済みデッキは examples/laser_plasma_1d/ に、検証項目を再現する独立したデッキ集は examples/verification/ にある。

要点

  • CBET のもの以外のプリセットは、終了時刻までの計算と、2 倍細かいメッシュの計算との比較まで済ませてある。Studio の各カードの「検証の run」にその結果が出る。
  • メッシュはメッシュ推薦スキル (tenryu-mesh-1d) で作った: レーザー照射のものは推薦メッシュ、輻射温度や圧力で駆動するものは層ごとの指定である。
  • 既知の問題も結果と一緒に書いてある: 球の Marshak 駆動で細かいメッシュの外側の境界のセルが加速し続けること、SNB の箔の吸収エネルギーのメッシュ依存、物性表の箔の値の切り詰め、衝撃波の後ろの密度の 0.6 % の差。
  • 回帰試験の標準的な参照は examples/verification/gxii_1d_fld_regression.py — GXII ベンチマークデッキ（GXII = 激光 XII 号、大阪大学レーザー科学研究所の 12 ビームレーザー）である。

実行可能なテンプレート（examples/templates/）

最初の 1 本には、全ブロックへコメントを付けた実行可能な雛形をそのまま使うのが早い。編集不要で完走する。コピーして名前を変えてから改造すること。実行手順はシミュレーションの実行にある。

1 次元レーザープラズマ例題集（examples/laser_plasma_1d/）

典型的なレーザープラズマ実験をモデル化した、コミッショニング済みの 1 次元デッキをまとめている。

  • 収録する 10 本は、箔の衝撃波ブレークアウト、2 パルス衝撃波タイミング、インピーダンス整合、爆発箔、Kr 中の輻射衝撃波、円筒ライナー、固体球収束（600/900/1350 セルの調査）、D2 充填シェル爆縮、CBET とホット電子を含むコロナ、Marshak 駆動の DT 燃焼を扱う。
  • 各デッキの状態、測定したコミッショニング指標、注意点は、例題集の README に記録している。
  • 固体材料が用いる tmat EOS 表は、ライセンスされた PrOpacEOS 由来のため配布しない。利用者は自身の PrOpacEOS/SESAME ワークフローから tools/tmat/propaceos_to_tmat.py で生成する必要があり、うち 1 本のデッキには SESAME ASCII ライブラリも必要である。

実際の計算で検証したプリセット

実行手順: TENRYU Studio でプリセットを適用してデッキ（namelist）を保存し、実行の手順どおり tenryu run に渡す。

表の値は、プリセットが意図したとおりの問題を構成できているかを判断するための、観測の目安である。GPU、バイナリ、解像度、終了条件、物性値を変えたデッキに対してまで通用する基準解ではない。「メッシュの差」は、同じ条件を 2 倍細かいメッシュで計算した結果との差である。平面のプリセットでは後面 (r = 0) が固定の壁で、両面から照射した箔の中央面にあたる。

結果の読み方

圧力で駆動する衝撃波は、計算の基本的な確かめ方の手本になる: 衝撃波の位置の時間変化から速さを測り、衝撃波の後ろの密度・流速とともに Rankine–Hugoniot の厳密な値と比べる。輻射熱波では、壁の温度だけでなく温度分布の全体を見る。先端の位置は、密度・不透明度・比熱のどれを変えても同じ値には保たれない。

レーザー照射のプリセットでは、入射したレーザーエネルギーと沈着したレーザーエネルギーの比から吸収率を読み、アブレーション圧は衝撃波が後面の壁に届くまでの平均で評価する。平面の箔の後面は固定の壁なので、壁に届いた後の圧縮は反射した衝撃波によるもので、爆縮の停滞ではない。球の爆縮では、最大密度と停滞の時刻を implosion/rho_peak などのステップごとの履歴から読む。爆縮の最大密度は短時間しか続かないため、間引かれたスナップショットの最大値ではなく履歴を使うこと。冷たい固体表面だけを置いて合成コロナもコロナ層も外すと、光線は吸収される経路をもたず臨界面の近くで反射し、駆動が成立しない。

結果がメッシュに依存しないかは、同じ条件を 2 倍細かいメッシュで計算して確かめる (Studio のメッシュの節の「収束確認用の組」)。上の表のメッシュの差はその比較の結果である。差が目安を超えるものと、細かいメッシュでだけ現れる欠陥は、表と Studio のカードに書いてある。

吸収率の数字と、その異なる条件

本ドキュメントには条件の異なるレーザー吸収率がいくつも登場するが、照射幾何と不透明度モデルが異なるため、互いに比較できない。

  • 約 93% — GXII 基準回帰デッキ（2026-09-25 の基準解）：f/3 の 12 ビームが 200 µm の super-Gaussian スポットで半径 250 µm のターゲットを覆う広い照射。固定不透明度・理想気体のベンチマーク物理。
  • 89% と 67% — Studio の平面の箔のプリセット (351 nm・1×1014 W/cm² の平面照射) と球殻の爆縮のプリセット (527 nm のガウス波形、外半径 250 µm の CD 殻)。どちらも 2026-10-01 の計算で、波長・強度・ターゲットが回帰デッキとは異なる。
  • 約 45% — HELIOS とのコード間ベンチマーク（照射条件をそろえた LTE 比較。2026 年 7 月の測定）：意図的に狭い約 113 µm のガウススポットをほぼ平行ビーム（f/191）で与え、LTE テーブル不透明度を使用（検証とベンチマーク参照）。

吸収率は波長、強度、スポット径、ビーム開口、不透明度モデルに強く依存するため、これらの数字が一致することは期待されず、一致しないことに意味もない。

検証用のデッキ集

examples/verification/ は、解析解、保存則、演算子の単体、統合的な回帰といった検査を再現するためのデッキ集である。ここではすべてのケースを列挙しない。レーザー直接照射、2 温度、流体、熱伝導、多群 FLD を、ひとつの実用的な 1 次元の経路で確認する標準的な参照が gxii_1d_fld_regression.py である。このデッキは基準解との回帰試験の入力であると同時に、初期のコロナ層がなぜ必要かという実装上の教訓をコメントに記録している。新しいレーザーのデッキを作るときは、設定の名前だけを写すのではなく、そのコメントと、パルス、材料の境界、出力の履歴を合わせて参照のこと。

プリセットは学習と新しいデッキ作成の出発点、検証用のデッキは契約の再現と変化の検出が主な目的である。前者の代表値が妥当に見えることと、後者の検査が通ることは互いに補い合う関係であり、どちらか一方で他方を代用できるものではない。
