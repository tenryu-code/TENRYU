検証とベンチマーク reference

TENRYU の検証は、個々のカーネルを閉じた形の解で固定する小さな検査から、基準解との回帰試験、再現性の監査、2D RZ の統合試験群、外部コードとの比較へと段階的に進む。上の段の試験ほど多くの物理を同時に通すが、下の段の解析的な検査を置き換えるものではない。各段は「どの契約が壊れたか」を切り分けられるよう、それぞれ異なる正解の基準と許容帯をもつ。

要点

  • 解析的な検査は、Sedov / Noh、多群 Marshak のスペクトル、SNB の Epperlein–Short 分散関係の帯、レーザーの屈折・吸収則などを、コード本体から独立した参照と比較する。
  • GXII の 1D FLD は、履歴上の爆縮指標を基準解と比較する。基準解は期待どおりに通すために動かす値ではなく、物理的に説明できる変更に限り、定量的なレビューを経て取り直す。
  • 決定論的な 1D の経路では、実行のたびにビット単位で一致することが基準である。2D RZ の一部は、atomicAdd の加算順序に由来する最下位ビットの差を、明示的な雑音帯として扱う。
  • I 系列は、グレイの輻射衝撃波、多群 FLD の一致、SN の輻射衝撃波の段階列を、2D RZ の連成条件での受け入れ判定へ引き上げる。

検証の階層

この階層は、単一の演算子に対する数式、構成を固定した数値の軌道、実行ごとの再現性、複数の演算子の連成、別実装との比較、という順に証拠を積み上げる。小さな検査は符号・単位・係数・境界条件の誤りを局所化し、統合試験群は、正しい部品が実際の時間ループ、メッシュ、台帳のなかでも整合することを確認する。外部コードとの比較は妥当性確認の補助的な証拠であり、内部の検証の代用にはならない。

検査の種類何を検査するかどこで走るか
1. 単体・解析解単一のカーネル、離散演算子、保存の恒等式を、閉じた形の解や独立な実装と比較する。ctest の verify_sedov、verify_noh、Marshak / SNB / レーザーの各パターン。対応する多くは tenryu verify <name> でも実行できる。
2. 基準解との回帰固定したデッキの履歴指標が、承認済みの JSON の基準値と許容差の範囲で一致するかを検査する。ctest -R verify_gxii_1d_fld_regression または tenryu verify gxii_1d_fld_regression。
3. 再現性同じ入力での反復実行や、必要に応じてランク数を変えた実行を、T-bit / T-sum / T-noise の契約（後述の凡例参照）で比較する。文書化された parallel_determinism_audit の契約と、各連成試験群における反復実行・機能オフの経路。
4. 統合試験群2D RZ で流体、輻射、材料との結合、メッシュ、境界の台帳を同時に検査する。CTest の I1 / I2 / I3 の試験群。完全に連成した行は strict を名前に含み、長時間かかる行には expensive のラベルが付く。
5. コード間ベンチマーク入力の物理的な意味をそろえたうえで、別のコードと傾向や吸収量を比較する。HELIOS との照射条件をそろえた LTE のキャンペーン。コミットごとの通常の検査ではなく、記録を伴うベンチマークである。

解析解・単体検査のカタログ

解析解による検査の価値は、単に実行が完走することではなく、実装が誤っていれば異なる値を返す「正解の基準」をもつことにある。可能な箇所では、参照となる計算は実運用のカーネルと同じ補助関数を呼ばず、独立な積分、離散的な固有値、あるいは文献の解から作る。

対象参照と主な観測量代表的な検査の名前
流体Sedov–Taylor の爆風は、衝撃波の半径・密度分布・エネルギーを相似解と照合する。Noh は、衝撃波の位置、圧縮のプラトー、外向きの流れ、保存を、幾何ごとの解析値と照合する。sedov、noh、noh_planar、noh_cylindrical
多群 FLD8 群の Marshak のプラトーを、独立なプランク積分から得たスペクトルと照合する。振動数に依存する緩和では、群ごとの不透明度の配線を、閉じた形の後退オイラー応答で検査する。fld_1d_mg_planar_marshak_spectrum、fld_1d_mg_planar_freqdep_relaxation
SNB 熱伝導離散的な分散関係との厳しい比較と、Epperlein–Short や VFP（Vlasov–Fokker–Planck 運動論計算）のデータに基づく物理的な帯 [4,5] とを分離する。格子と群の段階列、単調性、局所極限、保存も同じ試験群で確認する。snb_local_limit_1d、snb_dispersion_1d、snb_conservation_1d
レーザー・不透明度一様な媒質での Beer–Lambert 減衰、解析的な屈折率分布における転回点、3 次元光線の吸収と沈着の台帳を検査し、rho*kappa の掛け忘れや二重掛けも検出する。beer_lambert、laser_3d_beer_lambert、laser_3d_refraction
輻射の波面Hammer–Rosen の超音速 Marshak 波 [3] について、波面の等値面と、入射・逸出のエネルギー台帳を摂動論の解析解と照合する。hammer_rosen_supersonic

許容差は一律ではない。たとえば決定論的な Beer–Lambert の光線追跡は統計誤差をもたないため、厳しい相対誤差を要求できる。一方、文献の図から読み取った SNB の物理的な帯は、離散演算子の精度に対する検査とは分けて扱い、モデルの既知の適用限界までを「合格」に見せないよう、対象とする段を明記する。

GXII ベンチマーク

本ドキュメントで GXII とは、激光 XII 号（GEKKO XII）— 大阪大学レーザー科学研究所の 12 ビーム Nd:ガラスレーザー — のことである。TENRYU の常設アプリケーションベンチマークは GXII 相当の直接照射爆縮で、正十二面体の面に配置した 12 ビーム（実装上は正二十面体の 12 頂点方向）が 500 µm カプセルを照射する。基準回帰デッキ examples/verification/gxii_1d_fld_regression.py は次の構成を凍結している。

項目回帰デッキでの値
ターゲットCH シェル（\(\rho=1.05\) g/cm³、厚さ 20 µm、外半径 250 µm；\(A=6.5\)、\(Z=3.5\)）と内側の DT ガス（0.010 g/cm³；\(A=2.5\)、\(Z=1\)）。外側は VOID。
シード・コロナ指数ランプ \(\rho=0.05\,e^{-(r-250\,\mu m)/2\,\mu m}\) g/cm³（延長 10 µm、裾ガード \(3\times10^{-4}\) g/cm³）。351 nm での CH 臨界密度（0.028 g/cm³）を分解されたランプ内に置く。
駆動10 kJ / 1 ns 矩形パルス（総計 10 TW、10 ps ランプ）、\(\lambda=351\) nm（3ω）；f/3 の 12 ビーム、super-Gaussian スポット（\(w_0=200\) µm、\(m=4\)）、ビームあたり 1000 本の弦追跡。
物理2 温度ラグランジュ流体、Spitzer–Härm 伝導、20 群 FLD（対数境界 0.01–100 eV、Levermore–Pomraning リミッタ）；理想気体 EOS（\(\gamma=5/3\)）、固定不透明度 \(\kappa=100\) cm²/g、完全電離固定 \(\bar Z\)。CBET・ホット電子はオフ。
格子・時間0–500 µm を 200 セルの一様ラグランジュ格子、2 ns まで。

各カーネルページが引用する「GXII」条件 — 基準吸収率、コロナのサブステップ数、S8/S16 比較、Studio の「GXII 級」プリセット — は、このデッキまたはその明示された変種を指す。「GXII 級」と書かれた箇所の物理的定義は、この表のターゲットと駆動のパラメータである。

基準解との回帰と、その取り直し

verify_gxii_1d_fld_regression は、レーザー、流体、熱伝導、2 温度の物質、FLD を通る 1D 球対称爆縮の、実運用向けの回帰試験である。最終スナップショットではなく履歴から、吸収したレーザーエネルギー、最大圧縮時刻、rho_peak_max、面密度 rhoR_max、中心温度 Tc_max を取り出す。現在の契約では、rho_peak_max は基準解から相対 10% 以内、最大圧縮時刻は 5% 以内、その他の主要な履歴指標は指定された物理的許容差の範囲であることを要求する。shell_r_min は参考値である。run_profile(格子・実行長など実行条件の記録)が一致しない場合は比較そのものを失敗させ、短縮した実行や別の格子を同じ基準値への合格に見せかけられないようにしている。

基準解は「正解であることの証明」ではなく、同じ格子と実行プロファイルにおける変化の検出器である。取り直しが許されるのは、既知の不具合の修正、物理アルゴリズムや基準となる数値パラメータの変更、あるいはコードの責任者が承認した理由がある場合だけである。更新には、理由、旧値と新値の定量的な差、複数解像度での収束データ、そしてレビューを伴わせる。説明のない許容差の緩和や、失敗した実行の値へ合わせにいくことは、更新の理由にならない。

再現性の検査と 2D における例外

再現性の契約はティア名で呼ばれる。各カーネルページに現れるタグは次のとおりである。

ティア契約
T-bit反復実行間（宣言があればランク数を変えた実行間も）のビット単位の一致。
T-sumMPI の縮約順序だけが変わり得る場合。正規化した差を、通常 \(10^{-8}\) で判定する。
T-noise文書化された 2D RZ の atomicAdd 最下位ビット機構。受け入れは、反復実行から自己較正した帯、またはアンサンブルから凍結した帯による、デッキ・指標限定の契約。
OFF-bit機能を無効化（または一度も発火させない）した実行が、その機能なしの経路とビット単位で一致すること。
envelope文書化された非決定性をもつ指標に使う、参照実行のアンサンブルから較正した、より広いデッキごとの最悪値の帯。

決定論的な 1D の経路では、同じバイナリ・入力・GPU 構成による実行について、場と主要な診断量が実行のたびにビット単位で一致することを要求する。GXII の 1D では、レーザーの沈着を光線ごとの専用領域と固定順序の総和に変えた結果、全軌道をビット単位で再現できることが検査の前提になった。物理量に対する広い許容差はツールチェーンの頑健性のために残っていても、同じ構成での反復実行に差を許す根拠にはしない。

2D RZ の流体におけるコーナー力や一部の集計では、多数のスレッドによる atomicAdd の順序が実行ごとに変わり、最下位ビットの差を生み得る。この文書化された例外では、ビット単位の一致を誤った正解基準としては使わず、同じ構成での反復実行から自己較正した雑音帯、または凍結したアンサンブルによる帯を使う。長い実行では、最初のステップが完全に一致することと、終端での差が実行の長さに応じた成長の帯に収まることを、別々に検査する。これは恣意的な許容差ではなく、対象とするデッキと指標を限定した T-noise の契約である。決定論的な中間量や 1D の経路は、引き続きビット単位で一致しなければならない。

I 系列の 2D RZ 統合試験群

I 系列は単一の「2D 簡易試験」ではなく、参照問題を段階的に、連成した実運用の経路へ移していく階層である。各ハーネスはデッキを複数の角度、不透明度、格子、あるいはソルバの段で実行し、要約 JSON のすべての検査が閉じたときにだけ試験群を合格とする。

試験群検査する連成の契約CTest での見つけ方
I1: グレイ輻射衝撃波の基準点半解析的なグレイ輻射衝撃波の基準解 — LR07 と LE08 [6,7]、およびリミッタを切った FLD-CED の ODE 参照（タグ凡例参照）— を 1D で、さらに 2D RZ の z 方向スラブの脚（半径方向に薄いスラブ内を z 方向に走る平面衝撃波で、半径方向の不変性を判定）を用い、衝撃波、前駆領域、保存、参照分布への一致を固定する。ctest --test-dir build -R "I1|i1"
I2: 多群 FLD のグレイ一致振動数に依らない不透明度のもとで、多群 FLD の群についての和が連成したグレイ計算へ収束すること、波面のコーシー・リチャードソンによる収束、健全性監査（NaN・フロア発動・台帳の整合性検査）と保存を検査する。ctest --test-dir build -R "I2|i2.*mgfld"
I3: SN 輻射衝撃波の段階列角度の段、不透明度のスケール、格子の段階列を横断し、輻射の分布、流束、前駆領域、物質側の衝撃波、保存、FLD との順序関係、半径方向の不変性を検査する。ctest --test-dir build -R "I3|i3.*radshock"

I1 の連成する行と、I2 / I3 の完全な受け入れ判定は、試験の名前に strict を含み、部分的な簡易試験ではなくハーネスの必須項目をすべて評価する構成である。Catch2 の [.expensive] タグは CTest の expensive ラベルとして公開され、長時間かかる GPU の試験群を短い開発ループから分離する。これは品質を弱める印ではなく、実行時間とキャンペーンの規模による分類である。

ゲートタグの凡例

各カーネルページは検査の族を短いタグで略記する。タグは名前であって強さの序列ではない。「rung（段）」はひとつの試験群の内部段階列（角度分解能の段階列など）を、「tier-1」は意図的に縮約した第 1 世代モデルの契約を指す。

タグの族意味
L1 / L2（レーザー）レーザー検査の階層。L1 = 単一物理のレーザー閉包契約（屈折・Beer–Lambert・エネルギー台帳・光線数収束）、L2 = レーザー+流体の連成契約。誤差ノルムの \(L_2\)/\(L_\infty\) とは無関係。
G1–G4（熱伝導）SNB 非局所伝導の検査系列。G1 = 局所モデルとの OFF-bit、G2 = 局所極限と 2 次漸近、G3 = Epperlein–Short 分散、G4 = 保存。
G-R / G-K / G-P / G-L（核燃焼）領域別の燃焼検査系列。R = 反応率と燃料消費、K = Fraley の飛程・カーネル、P = 電子・イオン分配、L = エネルギー台帳。
B1 / B2 / N1 / W1–W8（粘性）Braginskii 粘性の試験群。B = 係数・歪み・減衰の検査、N1 = 曲率幾何モードの検査、W = 電子チャネルと 2D パリティ移植の系列。
H1 / H2（2D 流体）2D RZ 流体の参照デッキ。H1 = 平面 Sod、H2 = 円筒 Noh。
I1 / I2 / I3 / I62D RZ 統合試験群。I1 = グレイ輻射衝撃波、I2 = 多群 FLD のグレイ一致、I3 = SN 輻射衝撃波の段階列、I6 = SN 多群グレイ一致の受け入れ判定。
R2（SN）SN の求積・Marshak 参照試験群（座標の段階列と独立な Marshak 分布比較）。EOS の電荷モーメント \(r_2\) とは無関係。
LR07 / LE08 / FLD-CED（I1 の基準点）I1 を固定する参照解。Lowrie–Rauenzahn 2007 と Lowrie–Edwards 2008 の半解析的グレイ輻射衝撃波 [6,7]、およびフラックスリミッタを切った（エディントン因子 1/3 固定の）グレイ FLD を ODE として積分した参照（「FLD-CED」）。

HELIOS との 1D コード間ベンチマーク

HELIOS — Prism Computational Sciences の商用 1D ラグランジュ輻射流体コード — との LTE（局所熱力学平衡）比較では、単に同じ公称レーザーパワーを与えるのではなく、照射条件を対応させたケース — 約 113 µm のガウススポットをほぼ平行ビーム（f/191）で与え、両側とも LTE テーブル不透明度 — を用いることで、初めて意味のある比較の土台が得られた。その条件で測定した吸収率は TENRYU が約 45%、HELIOS がケースにより約 55〜73% であり、この差については要因の帰属を調べた記録が残されている。これらの数字は基準デッキの吸収率 83–84% とは意図的に比較不能である：基準デッキは f/3 の 12 ビームが 200 µm の super-Gaussian スポットで半径 250 µm のターゲットを覆う、はるかに広い照射幾何である（3 つの吸収率と条件の対照は「例題とプリセット」ページ参照）。この比較だけをもって、どちらかの実装の正しさや実験の再現性を主張するものではない。

実行方法

CTest はビルドツリーに登録された検査をパターンで選び、tenryu verify は単一の検証ドライバを直接起動する。

ctest --test-dir build -R <pattern>
./build/tenryu verify <name>

# Examples
ctest --test-dir build -R "sedov|noh|snb|gxii_1d_fld"
./build/tenryu verify snb_dispersion_1d

利用できる CTest の名前は ctest --test-dir build -N で確認できる。長時間の試験群を明示的に選ぶ場合は -L expensive、通常の確認から除外する場合は -LE expensive を使う。検査はビルドオプション、HDF5、MPI、GPU の実行環境に依存するため、スキップを合格と読み替えず、CTest のラベルと実行ログを結果と一緒に保存すること。
