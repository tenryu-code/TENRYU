Overview

TENRYU is organized as a set of physics operators advanced by Strang splitting around a compatible Lagrangian hydrodynamics core. This section explains the code's scope and design principles, the module architecture, the numerical foundations shared by all kernels, and the verification philosophy that gates every change.
