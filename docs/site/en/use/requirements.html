System requirements reference

TENRYU is a CUDA-only GPU code. This page collects the machine, GPU, compiler, and library requirements for building and running it in one place. The Building page covers the procedure; this page covers the conditions under which that procedure works.

At a glance

  • Required: an NVIDIA GPU plus CUDA Toolkit 12.x (12.0+), a C++20 compiler (GCC 12+ / Clang 15+), CMake 3.25+, Ninja, and Python 3.10+ (with development headers).
  • The default CUDA architectures are 70;80;89;90 (a Volta/Ampere/Ada/Hopper fatbin). Continuously exercised hardware: A100 (40/80 GB), RTX 4090, RTX 3090.
  • MPI and Hypre are opt-in (default OFF); HDF5 and Python are default ON. The small test/logging dependencies (Catch2/spdlog/CLI11/pybind11) are fetched automatically at configure time if missing — offline machines need them preinstalled.
  • All development and validation experience is on Linux x86_64; other operating systems are untested.

Platform and GPU

The only supported backend is NVIDIA CUDA (other backends such as HIP are out of scope by design). Without a GPU the code may build but cannot run. The basic execution shape is one process = one GPU: a single GPU needs no MPI, and multiple GPUs run as one MPI rank per GPU (see below).

Toolchain and libraries

The canonical minimum versions live in docs/ARCHITECTURE.md §2.2 in the repository. Requirements fall into three tiers: required, default-ON (removable but normally used), and opt-in.

About networking. Catch2, spdlog, CLI11, and pybind11 are downloaded by CMake's FetchContent at configure time when not found on the system, so the first cmake is easiest with internet access. On offline machines (e.g. compute nodes of a computing center), preinstall them or run the first configure where the network is available. CUDA, HDF5, Python, MPI, and Hypre are never auto-fetched and must always be preinstalled.

Pre-flight checks

If the following four checks pass, the required conditions are essentially met.

# GPU and driver (CUDA Version must be 12.x or newer)
nvidia-smi

# CUDA compiler (release 12.x)
nvcc --version

# Build tools
cmake --version     # 3.25 or newer
ninja --version

# Python (3.10+, with development headers)
python3 --version
python3 -c "import sysconfig, pathlib; p = pathlib.Path(sysconfig.get_paths()['include'], 'Python.h'); print(p, 'OK' if p.exists() else 'MISSING')"

Once these pass, continue to Building; that page also covers what to do when CMake reports a missing package.
