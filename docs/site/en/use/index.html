Using TENRYU

This section covers the whole practical workflow: checking the system requirements, building, completing a first run, writing Python namelist decks (or generating them with TENRYU Studio), and reading the HDF5 outputs. Following the quick start and the path below, this section alone takes you to a completed first run.

Quick start (copy and run)

If unsure about prerequisites, start with the pre-flight checks on System requirements. Everything below runs from the repository root.

# 0. get the source (first time only)
git clone https://github.com/tenryu-code/TENRYU.git
cd TENRYU

# 1. build (first time only; details and failure handling on "Building")
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
ninja -C build

# 2. smoke check (one registered analytic case)
./build/tenryu verify noh

# 3. first run (the template completes unmodified)
./build/tenryu validate examples/templates/template_1d_slab_radiation.py   # pre-flight check
./build/tenryu run      examples/templates/template_1d_slab_radiation.py  # the run

# 4. look at the results
ls outputs/template_1d_slab_radiation/results/
python3 -m tools.tenryu_plot profile outputs/template_1d_slab_radiation

(tools.tenryu_plot uses numpy, matplotlib, and h5py — see System requirements.)

Your first run: a suggested path

  1. System requirements — confirm the GPU and toolchain prerequisites.
  2. Building — get a binary and a passing ctest.
  3. Running simulations — complete a template through validate → run, exactly as written there.
  4. Examples & presets — run a verified preset, starting with laser_capsule, exactly as distributed.
  5. Outputs & analysis — read the result: absorption from the energy ledgers (incident versus deposited) and the implosion peak from the per-step history implosion/rho_peak.

When you need the physics behind a result, go to the matching physics kernel page; each page's mechanism section explains the background before the equations. How the time step is chosen is collected on Time-step control & CFL.
