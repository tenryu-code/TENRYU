Checkpoints and restart reference

A checkpoint <name>_ckpt_NNNN.h5 is an HDF5 file that stores, in addition to the contents of a snapshot, the internal state needed for a restart. This page describes the groups added to the snapshot content and the restart compatibility rules (schema_version and the check of the frozen configuration). File naming, the number of files kept, and the stop-request file are on the Outputs & analysis page; how to specify a restart is on the running page.

Checkpoint additions and restart compatibility

Checkpoints store the snapshot content plus the internal state needed to resume.

GroupContent
hydro_flags/hydro_activePer-cell hydro activity mask.
time_state/The step, t, and dt that the snapshot also holds, plus the cumulative energy terms and user_seed (the value of Main.seed). The restart Δt comes from here. A restart is refused with a ConfigError when Main.seed differs from user_seed.
output_state/Next scheduled output times (t_next_plot, t_next_history, t_next_checkpoint).
hydro/cv_e, cv_i, cs (1D)Heat capacities and sound speed obtained from the equation of state (EOS). A 1D restart from a checkpoint that has them does not redo the re-closure (definition), and the restarted run continues bitwise identical to the original run (except runs that reuse ray traces, Laser.raytrace_skip_config.enabled=True).
hydro_flags/cell_is_void (1D)Flags that mark the void cells (cells of a Material.is_void material; definition). A 1D run always writes it (zeros when there are no void cells); a 2D run writes it only when the run holds the mask.
conduction_state/Run-cumulative statistics of the conduction solver (maxima of the iteration count, the residual, and the condition number, among others).
burn_state/specific_inventoryNuclear-burn specific inventories \(Y_s\) [1/g] (per cell D, T, He3, He4, p). A restart uses these rather than the snapshot number densities hydro/burn_n_* divided by the density (since 2026-09-26).
radiation_sn/ (1D SN)Angular distributions of the linear-discontinuous scheme (psi_prev, psi_sd_prev) and the in-cell electron-energy offset (ee_node_offset); without them a run starts isotropic and flat in the cell.
particles/, rng/Only in schema-1 checkpoints. particles/ is the particle pool of the retired Monte Carlo radiation: read when empty, and a checkpoint holding particles is refused. rng/ is the RNG state, which a restart does not read. Neither is written from schema 2 (2026-09-29).

Restart compatibility: a checkpoint with the current schema_version (2 since 2026-09-29) is read normally, one with an older (or missing) version is read with backward-compatible defaults, and one with a newer version is refused. A restart is refused when the checkpoint's frozen configuration (the hash of the deck text and every setting except Main.restart_from) does not match the restarting deck. The running page explains how to specify a restart.
