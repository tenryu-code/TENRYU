TENRYU

A CUDA-native Lagrangian/ALE (arbitrary Lagrangian–Eulerian) radiation-hydrodynamics code for laser-driven high-energy-density (HED) and inertial-confinement-fusion (ICF) physics, in 1D spherical/cylindrical/planar and 2D axisymmetric (RZ) geometry.

TENRYU couples compatible Lagrangian hydrodynamics with multigroup radiation transport (flux-limited diffusion and discrete-ordinates SN), nonlocal electron conduction, laser ray tracing with inverse-bremsstrahlung absorption, cross-beam energy transfer (CBET), hot-electron generation and transport, tabulated or analytic EOS/opacity, and nuclear burn. Everything runs on the GPU; the unit system is frozen to cgs + eV. A form-based GUI (TENRYU Studio) generates and round-trips input decks. This documentation describes TENRYU version 1 (v1), the current production generation; see Nomenclature & conventions for the version vocabulary, abbreviations, and symbol table used throughout.
